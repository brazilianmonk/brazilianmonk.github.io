{% comment %} Target-page companion to the header search. When a page is opened with a #hl= fragment (appended by the search dropdown), this finds every case-insensitive occurrence of the query in the page's visible text, wraps it in , and scrolls to the first match. Matches are found against the flattened text of the main content, so phrases split across inline elements (e.g. , , cloze marks) are still found: each segment gets its own mark. Press Escape to clear the highlights. {% endcomment %}
