## All Conditionals

### 0 Conditional

- Purpose: general facts, habits, and rules — things that are always true.
- Structure: if-clause in the present, main clause in the present.
- Example:
    - If we do our job, we are recompensed. *(general truth)*

### 1st Conditional

- Purpose: to talk about a possible situation in the present / future.
- Structure:
    - if-clause in the present (can refer to the present / future),
    - main clause in the Future, Imperative, or Modal.
- Example:
    - If we do our job, we will be recompensed.
    - If we do our job, do yours as well.
    - If we do our job, you should inform the boss.

### Future Time Clause

- Purpose: only refers to the future.
- Structure: similar to the 1st conditional, using time conjunctions instead of *if*: when, as soon as, until, in case, etc.

### 2nd Conditional

- Purpose: express hypothetical situations in the present / future.
- Structure: if-clause in the past, main clause with would / could / might.
- Example:
    - If I had a lot of money, I would do this.

### 3rd Conditional

- Purpose: hypothetical situations in the past — things that did not happen.
- Structure: if-clause with the past perfect, main clause with would / could / might + have + past participle.
- Example:
    - If I had come home earlier, I would have seen him.

### Mixed Conditionals

The *time* of the if-clause and the *time* of the main clause need not match:

- **2nd → 3rd** (past consequence of a present/general condition):
    - If I were more careful *(now)*, I wouldn't have lost the keys *(then)*.
- **3rd → 2nd** (present consequence of a past condition):
    - If I had taken that job *(then)*, I would be living abroad now.
