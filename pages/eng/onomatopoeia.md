### Animals and Their Onomatopoeia

| Animal   | Common sound (onomatopoeia) | How their sound is called (verb/noun) |
|----------|-----------------------------|----------------------------------------|
| Dog      | Woof! Arf!                  | bark, howl, growl, whine               |
| Cat      | Meow! Purr! Hiss!           | meow, purr, hiss                       |
| Cow      | Moo!                        | moo, low                               |
| Pig      | Oink!                       | oink, grunt, squeal                    |
| Horse    | Neigh! Whinny!              | neigh, whinny                          |
| Sheep    | Baa!                        | bleat                                  |
| Rooster  | Cockadoodledoo!             | crow                                   |
| Chicken  | Cluck! Cackle!              | cluck, cackle                          |
| Duck     | Quack!                      | quack                                  |
| Bird     | Chirp! Tweet!               | chirp, sing, tweet                     |
| Lion     | Roar!                       | roar                                   |
| Elephant | (no common onomatopoeia)    | trumpet                                |
| Snake    | Hiss!                       | hiss                                   |
| Wolf     | Awoo!                       | howl                                   |
| Owl      | Hoot!                       | hoot                                   |
| Frog     | Ribbit! Croak!              | croak                                  |
| Bee      | Buzz!                       | buzz                                   |
| Donkey   | Heehaw!                     | bray                                   |
| Mouse    | Squeak!                     | squeak                                 |
| Bear     | Grrr!                       | growl, roar                            |
