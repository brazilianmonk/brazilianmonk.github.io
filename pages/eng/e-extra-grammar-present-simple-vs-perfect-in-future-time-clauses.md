Future Time Clauses have a structure similar to that of the 1st Conditional (Present -> Future/Modal/Imperative) but can be formed with either the Present Simple or the Present Perfect. 
- When I'm 40, I'll be a great elder.
- When you've finished your duty, you can go back home.

The Present Simple:
- more common
- the main clause action happens:
  - during the future time action
	- When we have dinner, we'll talk. (both actions together)
  - or after the future time action
	- When I find a job, I'll move out. (find it first, then move out)
Note: since the simple can be used for both during or after, when there is the need to emphasize or clarify the after, perfect is better.
	
The Present Perfect:
- less common
- the main clause action happens:
  - after the future time action
	- When we've had dinner, we'll talk. (first dinner, then talk)
- used to emphasize the need to conclude the first action before the next

| Main Clause Action vs. Time Clause Action | Tense Used      | Notes                                                                        |
| During                                    | Present Simple  |                                                                              |
| After                                     | Present Simple  | Ok, but if ambiguous or emphasis on conclusion is needed, better use perfect |
|                                           | Present Perfect | Makes clear it is after                                                      |
|                                           |                 | or emphasizes it must be after                                               |

| Purpose                                                        | Tense Used               |
| Conclusion of Time Clause action before the main clause action | Present Perfect (better) |
| To show both actions occur together                            | Present Simple           |
|                                                                |                          |
