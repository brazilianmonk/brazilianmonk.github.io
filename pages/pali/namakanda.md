## Gacchantādigaṇa


<a id="org63a17b0"></a>

### Definition, Gender, and Key Feature



-   **Definition**: The Gacchantādi Group consists of stems ending in "a" (akāranta), formed by adding the suffix *anta* to verb roots (e.g.,  *gacchanta* = "one who is going").
-   **Gender**: Declines in masculine and neuter forms, with distinct
    patterns.
-   **Key Feature**: Similar to the *guṇavādi* group, except for the
    nominative singular form in masculine declension (*gacchaṃ* with
    niggahīta ending).

## Satthādigaṇa


<a id="orga5ae1ac"></a>

### Overview



-   **Definition**: The Satthādi Group includes *ukāranta* (u-ending) stems
    like *satthu* (teacher), formed by adding the suffix *tu* to verbal
    roots.
-   **Declension Types**: Two declension charts exist based on gender:
    masculine and feminine.
-   **Purpose**: These stems denote agents or doers of actions (e.g.,
    teacher, doer, giver).

-   Special Cases for Satthādi &#x2013; āra, gender, -e, <del>suffix</del>

    
    
    -   **-āra**
        -   **"āra" substitution**:
            -   With suffix -to: "satthārato satthāraṃ gacchanti" ("They go from
                one teacher to another.").
            -   In compounds: "satthāradassanaṃ" ("Seeing the teacher.").
        -   **-āra > ara**:
            -   **pitu, bhātu, jāmātu (son-in-law)**
    -   **singular in plural contexts**:
        -   Like guṇavādi and gacchantādi, the singular form satthā can appear in plural contexts.
            -   "avitakkitā maccumupabbajjanti" ("Those who do not engage in reasoning approach death.").
                -   Note: avitakkitā is not a satthādi word (formed with *taddhita*
                    suffix *&#x2013;ita*), and Moggallānanissaya rejects this example
                    (Rūpasiddhibhāsāṭīkā 1, 208).
    -   **-e substitution**:
        -   **āl. ekv.**:
            -   kattu and khattu (minister)
                -   "uṭṭhehi katte taramāno, gantvā vessantaraṃ vada" ("Rise, O minister! Go quickly and speak to Vessantara.").
                -   "natthi hi bho khatte paraloko" ("Indeed, O minister, there is no
                    afterlife.").
        -   **sa. of nettu (leader)**: smiṁ > e = nette
            -   sabbā gāvī ujuṃ yanti, nette ujuṃ gate sati ("All the
                cows go straight when the leader ox walks straight.").
    -   **elision of suffix**
        -   kcyn: **Sakamandhātā and Mahāmandhātā**:
            -   ca./ch. ekv.: suffixes elided: sakamandhātu and Mahāmandhātu
    
    
    
    -   Cases in which āl. ekv. -e substitution occurs
    
        
        
        -   **Kaññādi** group: e.g., bhoti kaññe.
        -   **Brahmādi** stems:
            -   brahmā: brahme
            -   sakha (companion): sakhe
            -   isi (seer): ise
            -   muni (sage): mune
            -   kattu/khattu: katte, khatte
        
        **mem aid**: A virgin named "E" sees brahma, who gives her a companion (sakha), they see 2 mons (isi, muni) coming followed by ministers (kattu, khattu).    
        

-   Gender in Satthādi Words

    
    
    -   **Masculine** but can take feminine or neuter meanings without changing declension patterns.
        -   kattā itthī: "a woman who performs" (feminine).
        -   kattā puriso: "a man who performs" (masculine).
        -   kattā kulaṃ: "a family that performs" (neuter).

            -   8.2.2.2. Word Formation
            
                -   **Nominative/Accusative Plural (*aggayo*)**:
                    -   *yo* vibhatti substitutes final *i* with *a* (*aggi + yo > aggayo*)
                        (*166. yosu jhissa pume*).
                    -   Unique to masculine i-ending nouns, not feminine (*ratti*) or neuter
                        (*aṭṭhi*).
                -   **Instrumental/Ablative (*agginā*)**:
                    -   *smā* vibhatti is replaced by *nā* (*aggi + smā > agginā*), as
                        explained under *kammunā* in *Cittādi* group.
                    -   Applies to non-feminine *i* and *u*-ending stems: *daṇḍinā,
                        bhikkhunā, sabbaññunā* (not in *guṇavādi* due to unique
                        substitutions).
            
            -   8.2.2.3. Stems with Irregular Forms
            
                -   **Yo/Naṃ Substitution**:
                    -   Stems like *muni* replace *yo* with *no* and *aṃ* with *naṃ*:
                        -   Nominative/Accusative Plural: *munī, munayo, munino; muniṃ,
                            muninaṃ*.
                        -   Other nouns: *setṭhi* (wealthy man), *pati* (lord), *adhipati*
                            (lord), *senāpati* (general), *atithi* (guest), *sārathi*
                            (charioteer), *mahesi* (great sage).
                        -   Forms: *setṭhino, setṭhinaṃ, patino, patinaṃ*, etc.
                    -   **In Compounds**:
                        -   *sāramati + yo > sāramatino* ("Asāre sāramatino&#x2026;" &#x2013; "Those who
                            perceive essence&#x2026;").
                        -   *dhammānuvatti + yo > dhammānuvattino* ("Ye ca kho
                            sammadaññāte&#x2026;" &#x2013; "Those who live in accordance with
                            Dhamma&#x2026;").
                        -   *sugati + yo > sugatino* ("Saggaṃ sugatino yanti" &#x2013; "Those of
                            good nature go to heaven.").
                -   **Vocative Singular (*e* Substitution)**:
                    -   Stems *isi, muni* take *e* replacement: *isi > (bho) isi, ise; muni
                        > (bho) muni, mune*.
                    -   Also seen in *satthādi* group for *brahmā, sakha, kattu, khattu*
                        (*brahme, sakhe, katte, khatte*).
                -   **Locative Singular (*o* Substitution)**:
                    -   For stem *ādi*, *smiṃ > o* forms *ādo* (*ādismiṃ, ādimhi, ādo;
                        ādīsu, ādisu*).
                    -   Three words with *o* substitution: *ratto* (*ratti*), *ādo*
                        (*rattādi*), *raho* (*manogaṇa*).
                -   **Rare Substitution (*ne* for *smiṃ*)**:
                    -   *ariyavutti + smiṃ > ariyavuttine* ("kataññumhi ca posaṃhi,
                        sīlavante ariyavuttine" &#x2013; "Toward a man who is grateful, virtuous,
                        and of noble conduct.").

            -   **Vowel Shortening**: The final *ī* shortens in vocative singular
                (*daṇḍi*), accusative singular (*daṇḍiṃ*), and before certain
                vibhattis, similar to *itthī* (*itthiṃ*) (Rule: *parasaralopa* for
                accusative).

                *no* (*173. Yonaṃ none pume*), forming *daṇḍino*.
            -   **Accusative Singular (*daṇḍinaṃ*)**: *Aṃ* vibhatti replaced by *naṃ*
                (*174. Naṃ jhīto*), forming *daṇḍinaṃ*.
            -   **Locative Singular (*daṇḍini*)**: *Smiṃ* vibhatti replaced by *ni*
                (*176. Smiṃno ni*), similar to *Cittādi* group (*kammani*).
                Exceptions: *gāmaṇī, senānī, sudhī* do not take *ni* substitution.
            -   **Instrumental/Ablative (*daṇḍinā*)**: *Smā* replaced by *nā* (*166.
                yosu jhissa pume*), as in *agginā*.
            -   **Comparison**: From instrumental onward, *daṇḍī* follows *aggi*
                (i-ending masculine) patterns, adjusted for *ī*.

            -   **Yo to *A* Substitution**: Rarely, *ī* before *yo* becomes *a*, e.g.,

                kappeti&#x2026; brahmacārayo*).
            -   **Ne Substitution**: Rare replacements include:
                -   Accusative Plural: *assamaṇe* (stem *samaṇamāṇī*), *samaṇamānine*.
                -   Locative Singular: *arahantamhi tādine* (stem *tādī*).
            -   **Nesu for *Su***: Rare locative plural substitution, e.g., *verī + su >
                verinesu* (*Susukhaṃ vata jīvāma verinesu averino*).

### Extra Notes &#x2013; Overview

-   **Study Strategy**:
    -   Unique forms (najjo, najjā, itthiyaṃ, aggayo, sāno, ratto, ratyo, rattiyā, rattiyaṃ).
    -   Sandhi rules
        -   dy > jj for nadī
        -   v > b for pathavī
        -   ṇy > ññ for pokkharaṇī
    -   vowel shortening in:
        -   long vowel stems (itthiṃ, vadhuṃ)
        -   yā substitution (itthiyā, yāguyā)
    -   Irregular forms (*munino, ariyavuttine, ādo*)
-   **Some Key Rules**:
    -   "Yo" vibhatti shortens final long vowels (itthiyo, vadhuyo) or
        substitutes "a" (aggayo) (166. yosu jhissa pume).
    -   "Yā" substitution for singular cases from instrumental (85.
        ghapat-ekasmiṃ nādīnaṃ yayā).
    -   Parasaralopa for itthiṃ, yāguṃ (rukkha-sakuṇa-naya).
    -   Sandhi transformations: nadyo > najjo, pokkharaṇyo > pokkharañño.
    -   Connection to satthādi forms like matyā and petyā for comparative understanding.
    -   Si elision in nominative singular (ratti).
    -   Vowel lengthening when *yo* is dropped (rattī).
    -   Yā substitution for vibhattis from instrumental singular onward (rattiyā).
    -   "Yaṃ" for locative singular "smiṃ" (rattiyaṃ).
    -   "Ratto" as a unique locative form for ratti.
    -   Verse-specific shortening (ratyo, ratyā).

### Other Nouns



-   **muddha** (gead/top)
    -   Sattadhā me phale muddhā ("My head would break into seven

        rocky mountain top").

    -   asma: Mā tvaṃ adhammo ācarito, asmā kumbhamivābhidā ("Do not

    -   usma: Usmā āyuṃ paṭicca tiṭṭhati ("Body heat depends on life
        force"); Āyu usmā ca viññāṇaṃ ("Life, heat, consciousness").

    -   bhesma: Bhesmā hi udadhī mahā ("The ocean is terrifying and
        vast").

    -   **āṇima, mahima, laghima** (supernormal powers of the Buddha).

        -   rpsd (pg. 66): some sources: it declines like yuva
        -   sdnt: it is under guṇavādi group (magha + vantu > maghavā).
            -   Sakkasaṃyutta, Sakkanāmasutta: "Sakko, bhikkhave, devānamindo pubbe manussabhūto samāno magho nāma māṇavo ahosi, tasmā Maghavāti vuccati" ("Sakka, when human, was a youth named Magha, hence called Maghavā").
        -   **Conclusion**: it is a taddhita form (*magho assa atthīti maghavā*), more appropriately treated as guṇavādi.

## Sabbanāmagaṇa


<a id="org622dcbe"></a>

### introduction

-   Definition

    
    
    -   **“sabbesaṃ liṅgatthānaṃ sādhāraṇāni nāmāni sabbanāmāni”**
        Nouns that are common to the meanings of all stems are called sabbanāma
        -   Gist: **sabbesaṃ nāmāni sabbanāmāni**
            the "names of all" (nouns common to the meanings of all stems) are sabbanāma
    -   note:
        -   one of the 5 major noun types
        -   tiliṅgika
        -   it is a chaṭṭhī tappurisa samāsa
    
        
    
    -   5 types of nāma
    
        
        
        -   **kitaka** nāma: root + suffix
        -   **taddhita** nāma: kitaka + suffix
        -   **nāma** nāma: nouns
        -   **sabba** nāma: noun/pronoun declined in 3 genders
        -   **samāsa** nāma: combined nouns
        
        

-   Total #

    
    
    -   27 sabbanāma: kaccāyana (ta > tya)
    -   28 sabbanāma: moggallāna (ta, tya)
    
    

-   27 sabbanāmas into 6 groups

    
    
    1.  **sabba, katara, katama, ubhaya, itara, añña**
    2.  **aññatara, aññatama**
    3.  **pubba, para, apara, dakkhiṇa, uttara, adhara**
    4.  **ya, ta (,tya), eta, ima, amu, kiṃ**
    5.  **eka, ubha, dvi, ti, catu**
    6.  **tumha, amha**
    
    **Notes**:
    
    -   1 and 2
        -   declined as sabba
        -   possess 'i' form: katarissa (exc. sabba and ubhaya)
    -   3: declined as sabba with added purisa forms
    -   4, 5, and 6
        -   no ālapana
        -   their own individual declensions
    -   6: aliṅgika &#x2013; same declension for all 3 genders
    -   **tya** (mgln)
        -   “khiḍḍāpaṇihitā tyāsu”; jātaka abhinavatīkā (V. 4, pg  141): tya is either a form of ta or another pronoun; due to its rarity, it is not included
    -   **upari** and **adho** are nipātas, so they are not included here
    
    
    
    -   Meanings
    
        
        
        -   *sabba*: all
        -   *katara, katama*: which (interrogative)
        -   *ubhaya*: both
        -   *itara*: the other, the rest
        -   *añña*: another, different
        -   *aññatara, aññatama*: a certain one (indefinite)
        -   *pubba*: former, east
        -   *para*: later, another, west
        -   *apara*: another, western
        -   *dakkhiṇa*: south
        -   *uttara*: north
        -   *adhara*: lower
        -   *ya*: who, which
            -   like a relative pronoun; makes the clause dependent; paired with "ta"
        -   *ta*: he, she, it, that
            -   ta: demonstrative, can be by itself
        -   *eta, ima*: this
        -   *amu*: that, such, so and so
        -   *kiṃ*: what
        -   *eka*: one, certain, superior (ekodibhāvaṁ eko udi bhāvaṁ)
        -   *ubha*: both, collection of 2
        -   *dvi*: two
        -   *ti*: three
        -   *catu*: four
        -   *tumha*: you
        -   *amha*: I/we

    -   **añña**: arahatship (aññaṃ byākāsi)
    
    

-   Sabbanāma Usage in Samāsas

    
    
    -   **Dvanda Samāsa**:
        -   pa./āl. bhv.: yo > e (*:q: maybe ā here*)
            -   "pubbo ca aparo ca pubbāparā" ("the former and the latter
                person"). (*:q: why is the example with ā?*)
        -   pa. bhv. also allows pubbāpare (unique to pronouns);
        -   ch. bhv.: **pubbāparānaṃ**, not pubbāparesaṃ or pubbāparesānaṃ.
        -   Extra Notes:
            -   3 characteristics of dvandasamāsa
                -   independent: nouns are not visesana and visesya, they are independent nouns
                -   ca: the indeclinable “ca” collects the two nouns
                -   equal prominence: in the final compound both words are equally prominent in their meaning
    -   **Bahubbīhi Samāsa**:
        -   Generally, compounds focus on the non-pronoun meaning (aññapada)
            and are not declined as pronouns.
            -   Exception: Directional pronouns (*pubba, apara, dakkhiṇa, uttara*)
                in *bahubbīhi* compounds are declined as pronouns.
                -   dakkhiṇapubbā ("southeast direction") &#x2013; viggaha: dakkhiṇassā ca pubbassā ca yadanantarālaṃ, sā dakkhiṇapubbā (the direction between south and east).
                    -   Declines as a pronoun, e.g., *dakkhiṇapubbassā,
                        dakkhiṇapubbassaṃ*.
    -   **Tappurisa Samāsa**:
        -   Example: *māsena pubbo* ("prior by a month") &#x2013; not declined as a
            pronoun, though the reason is not specified.
    -   **Other Samāsas**:
        -   If the pronoun is not the main meaning, the compound is not declined
            as a pronoun.
            -   pubbe diṭṭho → diṭṭhapubbo ("seen before") &#x2013; declines as a regular noun, not a pronoun, as the focus is on "seen" rather than pubba.

### general declension principles

-   **Masculine (19 Pronouns: *sabba* to *ima*, plus *eka*)**:
    -   Stem ends in *a*, declines like *purisa* (e.g., *sabbo, sabbena,
        sabbehi, sabbassa, sabbasmā, sabbasmiṃ, sabbesu*).
-   **Feminine**:
    -   Adds feminine marker *ā*, declines like *kaññā* (e.g., *sabbā,
        sabbāyo, sabbāya*).
-   **Neuter**:
    -   Declines like *citta* (e.g., *sabbaṃ, sabbāni*).
-   **Pronoun *kiṃ***:
    -   Often changes to *ka*, behaving like an *a*-ending stem.
    -   Masculine: *ko, kena, kassa* (like *purisa*).
    -   Feminine: *kā, kāyo, kāya* (like *kaññā*).
    -   Neuter: *kaṃ, kāni* (like *citta*).
-   **Pronoun *amu***:
    -   *u*-ending stem.
    -   Masculine: Declines like *bhikkhu*.
    -   Feminine: Declines like *yāgu*.
    -   Neuter: Declines like *cakkhu*.
-   **Pronouns *ubha, dvi, ti, catu, tumha, amha***:
    -   Each has unique declension patterns.
-   **Unique Characteristics**:
    -   Pronouns may exhibit additional forms beyond standard *purisa*,
        *kaññā*, or *citta* declensions.

## Vibhattipaccayantapada


<a id="org529f021"></a>

### vibhattipaccaya and vibhattipaccayantapada &#x2013; definition

[

-   **vibhattipaccaya**: suffixes that show the meaning of vibhattis and stand in their place
    -   **vibhatyatthānaṃ jotakattā vibhattiṭṭhāne ṭhitā paccayā vibhattippaccayā**
        -   the suffixes that stand in place of the vibhattis are called vibhattipaccayas (case-suffixes) because they elucidate the meaning of the cases
-   **vibhattipaccayantapada**: words that end with case-suffixes
    -   stem + case suffix (purisa + to > purisato)
    -   considered nipātas
        -   aliṅga
        -   same form in both genders

]    


<a id="orgd8843a2"></a>

### 3 types of vibhattipaccayas

[

-   **ablative -to** suffix: purisato, rājato, aggito, itthito, etc.
-   8 **general locative meaning** suffixes
-   4 **temporal locative meaning** suffixes

]  

-   ablative -to

    -   meanings
    
        [
        
        -   **ablative**: primary usage
        -   **locative**:
            -   with nouns
                -   ādito - at the beginning
                -   majjhato - in the middle
                -   purato - in front
                -   piṭṭhito - behind
                -   puratthimato - in the eastern direction
            -   with prefixes abhi-, pari- and some particles:
                -   abhito - in front of
                -   parito - all around, surrounding
                -   heṭṭhato - below
                -   uparito - above
        -   **instrumental**: 
            -   rūpaṃ attato samanupassati (He regards form as self)
            -   pañcakkhandhe aniccato vipassati (He sees the five aggregates as impermanent)
        -   **nominative**:
            -   yatvādhikaraṇaṃ — “for whatever reason”
        -   **accusative**
            -   ito ehi — come here
            -   ito balāke āgaccha — O crane, come here
        -   **genitive** 
            -   paratoghoso — the voice of others
        -   note:
            -   all except dative
            -   here, according to frequency of usage
            -   these vibhattis can also be used in different meanings
        
        ]    
    
    -   6 changes caused by "-to"
    
        [
        
        -   1 shortening
            -   **long-ending-vowel -> short**: hatthito, sabbaññuto, kaññato, and itthito
        -   1 lengthening
            -   **chandadīghatā**: st, short vowel becomes long for metrical reasons
                -   darito **pabbatāto** vā, **rukkhāto** patito naro
                    cuto patiṭṭhaṃ labhati, yo mittānaṃ na dūbhati
                    (a man whho does not betray his friends obtains a firm footing even if he falls from a cleft, a mountain, or a tree)
        -   4 substitutions
            -   i-substitution
                -   **mātu, pitu** -> mātito, pitito
                -   **ima** -> ito
                    -   ima > i > ito
            -   e- / a-substitution
                -   **eta** -> etto, ato
                    -   eta > e + to > tto = etto
                    -   eta > a + to = ato
            -   ku-substitution
                -   **kiṃ** -> kuto
                    -   kiṁ > ku + to = kuto
        
        ]        

-   general vs temporal meaning of locative

    [
    
    -   **general meaning**: support or basis for an action
    -   **kālasattamī attha** (temporal locative meaning): time (kāla) as a kind of basis for actions
    
    ] 

-   8 general locative meaning suffixes

    [

    -   ima + **-ha, -dha**

    -   ya + **-hiṁ**

    ]

        [

        -   meaning: **in/at a place**

            -   sabbattha, sabbatra (in all places / everywhere)

                -   dullabho purisājañño, na so sabbattha jāyati (A noble man is rare; he is not born everywhere)
            -   ubhayattha, ubhayatra (in both places)
                -   idha nandati, pecca nandati, katapuñño ubhayattha nandati
            -   aññattha, aññatra (elsewhere, in another place)
                -   na bhikkhave aññatra paribhogo, aññatra paribhuñjitabbo.
                    Monks, (a saṅghika property) which is offered to be used in a certain place should not be used elsewhere.
                -   different meaning: aññatra bhikkhu sammutiyā
            -   yattha, yatra (where, in whatever place)
            -   tattha, tatra (there, in that place)
        
        ]

            -   ttha
                -   [kiṃ > ka + ttha] = kattha (where?)
                -   [eta > e + ttha] = ettha (here)
            -   tra
                -   [kiṃ > ku + tra] = kutra (where?)
                -   [eta > a + tra] = atra (here / in this place)
    
    -   -va &#x2013; added to what, meaning, example, formation
    
        [
        
        -   added to: **kiṁ**
        -   meaning: **where**

            -   kiṁ > k + va = kva (where?)
                -   tvaṃ pana bhante kva ahosi? (Bhante, where were you?)
        
        ]      
    
    -   -ha and -dha &#x2013; added to what, meaning, example, formation
    
        [
        
        -   added to: **ima**
        -   meaning: **here**
        -   e.g.:
            -   ima > i + ha / dha = iha / idha (here)
        
        ]    
    
    -   -dhi &#x2013; added to what, meaning, example, formation
    
        [
        
        -   added to: **sabba** = sabbadhi
        -   meaning: **everywhere, in all places**
        -   e.g.:
            -   namo te buddha vīratthu, vippamuttosi sabbadhi

            -   vippamuttassa sabbadhi

## Abyaya


<a id="org9704bc5"></a>

### Definition

[
**nānāliṅgavibhattivacanehi natthi rūpabyayo etesanti abyayā**
they are called abyaya because their form does not change due to differences of gender (liṅga), case (vibhatti), or number (vacana)

-   byaya = change

]  


<a id="orge9dc4e5"></a>

### 2 general categories of abyaya

[

-   nipāta
-   upasagga

]  


<a id="orgae3cb30"></a>

### 6 types of abyaya

[

-   **upasagga**
-   **nipāta**
    -   **vibhatti-paccayantapada**
    -   **tvādi-paccayanta kitaka**: root + tvā, tvāna, tuna, tuṁ, tave, etc.
        -   -tvā, -tvāna, -tuna: **nominative**: bhutvā, gantvā
            -   bhante: they seem to have non-nominative meanings as well, but the grammar only mentions nominative: gāmaṁ gantvā purisaṁ passāmi (gantvā modifies gāmaṁ in dutiya so should be dutiya)
        -   tuṁ, tave: **dative**: gantuṁ, gantave
    -   **abyaya taddhita**: yathā, kathaṁ (instrumental case)
-   **abyayībhāva samāsa**: upanagaraṁ
-   notes:
    -   those put under nipāta are called nipāta in many places
    -   additional vibhattis are not added to words ending with vibhattipaccayas since they occupy the place of vibhattis
    -   (*:q: under which of the 5 types of nāma is upasagga and nipāta included?*)

]     


<a id="orgea8766c"></a>

### Upasagga &#x2013; prefixes

-   introduction

    -   definition
    
        [
        **Upecca atthaṃ sajjanti saṅkharontīti upasaggā**
        they are called upasaggas because they approach (upecca) [roots and stems], modifying and transforming their meanings
        
        -   **upecca**:
            -   approach **roots**: abhikkamati
            -   approach **stems**: abhidhammo
        -   atthaṁ **sajjanti**: they "decorate" the meaning
        -   atthaṁ **saṅkharonti**: they "modify" the meaning (*:q: confirm*)
        -   notes:
            -   not declined
            -   normally added to the beginning of a root / noun, but st suffixed at the end of a noun (*:q: add example*)
        
        ]  
    
    -   why are they studied under the nāma chapter?
    
        [
        
        -   **vibhatyantaṁ padaṁ**: no sound becomes a word without a vibhatti
            -   nāmas have nāmavibhatti (si, yo, aṁ…)
            -   verbs have ākhyātavibhatti (ti, anti, si, tha…)
            -   upasaggas and nipātas have nāmavibhattis added to them to make them "usable", so they can be considered as nāmas
                -   they have the meaning of nominal cases, what shows vibhattis are applied to them
                -   after vibhattis are applied, they are elided
        
        ]

        -   different meaning: √dhā: (to hold):
            -   vidheti - arranges
            -   pidheti - closes
            -   nidheti - deposits
            -   saddahati - believes
    -   **anuvattate dhātvatthaṁ**: follow the meaning of the root without altering its meaning
        -   vijjati (exists) > saṃvijjati (exists)
        -   labhati (obtains) > paṭilabhati (obtains)
    -   **viseseti dhātvatthaṁ**: modify the meaning of the root
        -   √ñā (know)
            -   sañjānāti - recognizes
            -   avajānāti - despises, looks down upon
            -   abhijānāti - knows clearly or distinctly
            -   parijānāti - knows thoroughly

            -   āgacchati - comes
            -   uggacchati - goes up
            -   ogacchati - goes down

    tamevañño viseseti, upasaggagatī tidhā** (rpsd)
    some prefixes obstruct the meaning of the root. some follow the meaning of the root. others modify the meaning of the root. thus, the nature of prefixes is threefold.
    ]

### Nipāta &#x2013; indeclinable particles

-   3 definitions

    [
    
    -   (niccaṁ patanti) **niccaṃ ekarūpena vākyapathe patantīti nipātā**: they are called nipāta because they always fall (occur) in a sentence in the same form, without change
    -   (nipatanti) **padānaṃ ādi-majjhā-vasānesu nipatantīti nipātā**: they are called nipāta because they may fall (occur) at the beginning, middle, or end of words
        -   middle mean between visesana and visesya: mahanto ca / vā puriso
    -   **asatva-vācakā cādi-saddā nipātā nāma**: words such as ca, etc., which do not denote substances (things), are called nipāta
        -   substance, entity: purisa, etc.
        -   verbs also denote a substance as an agent or object
        -   they denote meanings such as conjunction (bringing things together)
    
    -   summary:
        -   they fall
            -   always in the same form
            -   in the beginning, middle, or end of words
        -   don't denote substances
    
    ]    

-   2 types

    [
    
    -   **vibhattiyutta nipāta**: associated with and convey case-meanings and function as subject, object, etc.
        -   āvuso: vocative particle; conveys the meaning of address, which belongs to the nominative case; treated as having nominative case
    -   **avibhattiyutta nipāta**: particles that do not associate with or convey case-meanings &#x2013; ca, vā, pana
        -   only the nominative singular is applied to them, merely to include them in the category of words
    
    ]
    
    -   vibhattiyutta nipāta acc. to case-meaning conveyed
    
        [
        
        -   **nominative**: applied to vocative particles
            -   āvuso
            -   bho
            -   bhante
            -   atthi
            -   natthi
            -   sakkā
            -   labbhā (it can be obtained)
            -   siyā (may be)
            -   siyuṃ (may be)
            -   sādhu
            -   tuṇhī, etc.
        -   **accusative**: in the sense of accantasaṃyoga (continuous duration)
            -   ciraṃ
            -   cirassaṃ (for a long time)
            -   niccaṃ
            -   satataṃ (always)
            -   abhiṇhaṃ
            -   abhikkhaṇaṃ (often), etc.
        -   **instrumental**:
            -   yathā
            -   tathā
            -   sabbathā
            -   sabbaso, etc.
        -   **dative**:
            -   kātuṃ
            -   kātave (for doing; to do), etc.
                -   tave = tuṁ
        -   **ablative**:
            -   samantā (from the surrounding)
            -   dīghaso (from the long side)
            -   oraso (from this side), etc.
        -   **locative**:
            -   pure
            -   purā
            -   pacchā
            -   uddhaṃ
            -   upari
            -   adho
            -   heṭṭhā
            -   antarā
            -   anto
            -   raho
            -   āvi
            -   hiyyo
            -   suve, etc.
        -   **namo**:
            -   if subject, nominative
                -   Namo te Buddha vīratthu (O Buddha, the Hero, may homage be (paid) to you!)
            -   if object, accusative
                -   Namo karohi nāgassa (pay homage to the Arahant)
        -   **sayaṃ**:
            -   if subject in active voice, nominative
                -   Kusūlo sayameva bhijjate (The granary itself breaks)
            -   if agent in passive voice (avutta-kattā), instrumental
                -   Sayaṃ kataṃ sukhadukkhaṃ (Pleasure and pain are produced by oneself)
        -   **iti** and **evaṃ**: according to context, all seven cases may be applied
            -   iti me sutaṁ: instrumental
            -   evaṁ me sutanti imaṁ sutaṁ: iti modifies the object of the sentence, so accusative
        
        ]

      h3Container.className = "toc-h3-list";
	h3Container.classList.add("collapsed");
      
	// Assemble
      li.appendChild(toggle);
      li.appendChild(a);
      li.appendChild(h3Container);
      tocList.appendChild(li);
      
      // Store references
      currentH2Item = li;
      currentH3List = h3Container;
      
      // Add click toggle functionality
      const toggleSection = () => {
        const isCollapsed = h3Container.classList.contains("collapsed");
        if (isCollapsed) {
          h3Container.classList.remove("collapsed");
          toggle.textContent = "▼";
          toggle.setAttribute("aria-label", "Collapse section");
        } else {
          h3Container.classList.add("collapsed");
          toggle.textContent = "▶";
          toggle.setAttribute("aria-label", "Expand section");
        }
      };
      
      toggle.addEventListener("click", function(e) {
        e.preventDefault();
        e.stopPropagation();
        toggleSection();
      });
      
      a.addEventListener("click", function(e) {
        // Allow normal anchor behavior, but also toggle if desired?
        // Comment out the next line if you want clicking the link to ALSO toggle
        // e.preventDefault(); 
        // Uncomment below to toggle when clicking the link text too
        // toggleSection();
        // Then scroll to heading
        // document.getElementById(heading.id).scrollIntoView({ behavior: "smooth" });
      });
      
    } else if (heading.tagName === "H3" && currentH3List) {
      // Add H3 item under current H2
      const li = document.createElement("li");
      const a = document.createElement("a");
      a.href = `#${heading.id}`;
      a.textContent = heading.textContent;
      li.appendChild(a);
      currentH3List.appendChild(li);
    }
  });
  
  // Insert TOC at the beginning of the page
  const firstHeading = document.querySelector("h1, h2");
  if (firstHeading) {
    firstHeading.parentNode.insertBefore(toc, firstHeading);
  } else {
    document.body.insertBefore(toc, document.body.firstChild);
  }
});
