## **sandhividhāna (the agreement of euphonic combinations)**

**8 main sandhis** - **lopo** - **dīgho** - **rasso** - **vuddhi** - **ādeso** - **āgamo** - **dvibhāvo** - **vipallāso**
### **loparāsi** (collection of elisions)
#### **saralopa (elision of vowels)
##### **26\. saro lopo sare.** (pubbasaralopa)

a vowel is elided when \[there is\] a vowel

**luppatīti lopo. sare pare sarūpo vā asarūpo vā pubbo saro lopo hoti.**

The letter that is elided is lopo. When / Because a vowel is succeeding, a vowel is elided, whether it is similar or dissimilar.

**lopo** can mean

the **act** of eliding

or **the letter** that is elided

**nimittattha** → the meaning of cause / reason - expressed by the locative case ⇒ because of

3 vibhattis used to express **the cause / reason**

tatiyāvibhatti: ann**ena** vasati

pañcamīvibhatti: avijjāpaccay**ā** saṅkhārā (sambhavanti)

sattamī (nimittattha): kuñjaro dant**esu** haññate (the elephant is killed because of its tusks)

sampajānamusāvād**e**...omasavād**e**...ujjhāpanak**e** khīyanak**e**...pācittiyaṁ

how can it be known to which vowel the elision should occur?

the elision occurs to the preceding vowel - that is shown by the sattamīvibhatti (because of the sutta no. 14 - sattamiyaṁ pubbassa)

**sarūpe tāva - avaṇṇe - lokaggo, bhavāsavo, avijjāsavo, avijjānusayo. ivaṇṇe - munindo, munīrito, varavādīrito, itthindriyaṃ. uvaṇṇe - bahūpakāro, bahukā ūmi bahūmi, sarabhuyā ūmi sarabhūmi, sarabhuyā udakaṃ sarabhūdakaṃ.**

4 examples to show all combinations (a a, a ā, ā ā, ā a...)

muni indo ⇒ mun*indo muni īrito ⇒ mun* īrito varavādī īrito ⇒ varavād*īrito itthī indriyaṁ ⇒ itth* indriyaṁ

bahu upakāro ⇒ bah*upakāro bahu ūmi ⇒ bah* ūmi sarabhū ūmi ⇒ sarabh*ūmi sarabhū udakaṁ ⇒ sarabh* udakaṁ

**ka** is used in bahu to make it feminine, but we should disjoin it as bahu ūmi

note: argument in favor of the double consonants being pronounced differently: long vowels are difficult to be pronounced before conjuncts

**asarūpe - sotindriyaṃ** (a i)**, kāmupādānaṃ** (a u)**, bhavesanā** (a e)**, bhavogho** (a o)**, so tuṇhassa** (i/ī a)**, diṭṭhānusayo** (i a)**, diṭṭhupādānaṃ** (i u)**, diṭṭhekaṭṭhaṃ** (i e)**, diṭṭhogho** (i o)**, mudindriyaṃ** (u i)**, puttā matthi** (me atthi)**, urassa** (uro assa) **dukkho, asantettha** (asanto ettha) **na dissanti iccādi. iti pubbaloparāsi.**

bhavesanā ⇒ bhava esanā

tuṇhi assa

tuṇhī is also correct

uro assa dukkho bhavissati - his chest will suffer

asanto ettha na dissanti (in this world the unvirtuous are not seen - in the buddha's eye, the wise , though far away, become clear to the buddha's eye, but the unvirtuous is not seen, like arrows shot in the dark (dhmp))

vocab: #\[\[**pāḷi** vocab (2nd year)\]\]

indo → ruler, lord, kind

īrita ↔ spoken

varavādī ↔ one who talks about the excellent

upakāra \[upa + √kar + \*a\] ↔ adj. helpful; useful; beneficial; supportive; lit. supporting 2 masc. help, support, favour

sarabhū → fem. name of a river; one of the five great rivers of ancient India

##### **27\. paro kvaci.** (parasaralopa)

the succeeding occasionally

**pubbasaramhā sarūpo vā asarūpo vā paro saro kvaci lopo hoti.**

the succeeding vowel, which may be similar or dissimilar from the previous vowel, is occasionally elided.

**sarūpe tāva - taṃ kadāssu** (ā a - nipātamatta) **bhavissati, kudāssu** (ā a) **nāma dummedho dukkhassantaṃ karissati, yadāssa** (ā a) **sīlaṃ paññañca, tadāssu** (ā a) **kaṇhaṃ yuñjanti -kaṇhanti mahākaṇhagoṇaṃ, taṇhāssa** (ā a) **vippahīnā, māssu** (ā a) **kujjha rathesabha, satthahārakaṃ vāssa** (ā a) **pariyeseyya, āgatāttha** (ā a) **tumhe, sotukāmāttha** (ā a) **tumhe, māyyo** (ā a) **evarūpamakāsi, papaṃ** (pa āpaṁ) **avinduṃ - pavaḍḍhaṃ āpaṃ labhiṃsūtyattho, nālaṃ kabaḷaṃ padātave - pa + ādātaveti chedo, gaṇhituntattho** (gaṇhitunta attho)**, ruppatīti rūpaṃ, bujjhatīti buddhā-dīgho, aggīva** (aggī iva) **tappati, itthīva** (itthī iva) **gacchati, nadīva sandati, mātupaṭṭhānaṃ** (u u)**, pitupaṭṭhānaṃ, yete** (ye ete) **dhammā ādikalyāṇā iccādi.**

**padātaveti paādātave, sandhivasena ākāralopo veditabbo, gahetunti attho.**

example where the commentary shows the parassara should be elided

if pubbassara were to be elided, the ā would have to be shortened; here the comm.

māradheyyaṁ pahātave - here pahātave means pahātabbaṁ, not tumanta

**asarūpe - itissa** (i a)**, itipi, assamaṇīsi** (ī a)**, akataññūsi** (ū a)**, vandehaṃ** (e a)**, sohaṃ, yassadāni** (a i)**, chāyāva** (ā i) **anapāyinī, mādisesu** (mādisā esu \[pubbassara\]) **kathāva** (kathā iva \[parassara\]) **kā, kinnumāva** (ā e) **samaṇiyo, madhuvā** (u i) **maññati bālo, cakkhundriyaṃ, dveme bhikkhave dhammā, tayome bhikkhave dhammā iccādi. kvacīti kiṃ? katamā cānanda (a ā) aniccasaññā.** (here pubbasaralopa) **iti paraloparāsi.**

**note**:

no sandhi / samāsa after ālapana - katamā cānand**a a**niccasaññā

**akulāsuno vaṇṇupathe khaṇantā udaṅgaṇe... (jātaka)** those who are not lazy, in the desert were digging, they experienced there a lot of water in that flat ground like this a sage possessed of the power of effort without being lazy you may also get the peace of mind (arahattaphala)

vocab: #\[\[**pāḷi** vocab (2nd year)\]\]

aṅgaṇa → flat ground

tāva ↔ ind. that much; that far; as long as; to that extent; until; at least; 2 ind. until later; for a while; 3 ind. firstly; to begin with

kadā / kudā → when

kvaci \[kva + ci\] ↔ ind. (gram) in some places; in some contexts; optionally; in several examples

##### **28\. na dve vā.**

optionally both not

**dve pubbaparasarā kvaci lopā na honti vā.**

alternatively, sometimes neither the preceding nor the succeeding vowels are elided

the meaning of **vā** in grammar suttas:

vikappena (alternatively, optionally)

when there is **vā** in an a vidhi, there can be two alternatives in which both are applicable:

ko imaṁ or komaṁ (vā)

**kvaci** "occasionally (compulsory)": shows that in some places there is a compulsory thing to do: sotindriyaṁ **vā** "optionally": shows that it can be done as an option, not compulsory: komaṁ / ko imaṁ

appamādamata / appamādomata does not occur

3 places where sandhi does not happen (from rūpasiddhi):

**chandabheda** (breaking the poetic meter): if a sandhi would break the poetic meter, it does not happen

**asukhucchāraṇaṭṭhāne**: in places that would be difficult to pronounce if sandhi happened

**sandhicchā rahitaṭṭhāne**: in places one has no desire to make a sandhi

example:

**appamādo amataṃ padaṃ, ko imaṃ pathaviṃvicessati.**

**kvacitveva** (kvaci iti eva kiṁ)**? sotindriyaṃ, cakkhundriyaṃ vāti kiṃ? komaṃ vasaliṃ parāmasissati** (who will touch this outcaste woman?)**.**

**ito paṭṭhāya yāvasandhikaṇḍāvasānā yuttaṭṭhānesu sabbattha kvacisaddo, vāsaddo ca vattante. tattha kvacisaddo nānāpayogaṃ dasseti. vāsaddo ekapayogassa nānārūpaṃ dasseti. lopanisedho.**

from here onwards until the end of sandhikaṇḍa in suitable places everywhere the term kvaci and the term vā occur. Here, (among these) the term kvaci many examples are shown. The term vā one example with different forms is shown.

Is restraint of elision.

vocab: #\[\[**pāḷi** vocab (2nd year)\]\]

payoga → example

nisedha masc. → (+gen & +abl) restraint (of) (from); prevention (of) (from); prohibition (of) (from); 2 adj. (+instr) restrained (by); controlled, (by); held back (by)

padaṁ ↔ upāyo

##### **29\. parasarassa.** (parasara of niggahīta)

**niggahītamhā parasarassa kvaci lopo hoti vā.**

Alternatively, in some places, the elision of the succeeding vowel from ṁ occurs.

**tvaṃsi** (ṁ a)**, candaṃva** (ṁ i) **vimalaṃ suddhaṃ, cakkaṃva** (ṁ i) **vahato padaṃ, halaṃdāni** (ṁ i) **pakāsituṃ , kinti** (ṁ i) **vadeyyaṃ, cīvaranti, pattanti, bhikkhunti.**

**iti saraloparāsi.**

#### **saṃyogādilopa** (elision of the first consonant of a conjunct)
**saṃyogassa ādibhūto byañjano kvaci lopo hoti vā.**

First consonant of a conjunct is alternatively elided in some places.

suttavutti: saṁyogassa, ādibhūto, lopo

anuvattanavutti: kvaci, vā

pakkhipanavutti: byañjano, hoti

note:

3 vutti

**suttavutti** (words directly mentioned in the sutta)

**anuvattanavutti** (words that are implied in the sutta - tbc)

**pakkhipanavutti** (words added by the grammarian)

- - - - - **pupphaṃsā uppajjati - idha pubbasuttena saralopo,**

pupphaṃ + assā ⇒ Her menstrual flux appears - Here, elision of the vowel happens by the previous rule.

- - - - - **evaṃsa te āsavā pahīnā honti,**

evaṃ + assa Thus, those defilements of his are eliminated

- - - - - **sace bhutto bhaveyyāhaṃ, sājīvo garahito mama - assa+ājīvoti chedo, bhaveyyāti attho.**

Bhaveyyāhaṃ + assa + ājīvo ⇒ bhaveyyāhaṁ ssa ājīvo ⇒ bhaveyyāhaṁ sa ājīvo mama ājīvo garahito assa (optative to be - as eyya ⇒ as sa If I become the one who has eaten, my livelihood would be blamed. (If I ate that, my livelihood would have become blameworthy). Cu ng (disjoining) should be done as assa + ājīvo. Bhaveyya (may be/would be) is the meaning (of assa).

**note**:

**sandhi** can happen between the **first and second**, or **third and fourth** lines of a verse not between the second and third

- - - - - **tīsu byañjanesu sarūpānaṃ dvinnaṃ ādibyañjanassa lopo - agyāgāraṃ, agyāhito, vutyassa, vityānubhūyate, ekasataṃ khatyā, ratyo, ratyā, ratyaṃ, sakvāhaṃ mārisa devānamindo, iccādi.**

Among three consonants, elision happens to the first consonants of the two similar consonants -

agyāgāraṃ: aggi + āgāraṃ (room for sacrificial fire) ⇒ aggyāgāraṁ ⇒ agyāgāraṁ

agyāhito: aggi + āhito (kindled fire)

vutyassa: vutti + assa (should be a person who has practice)

vityānubhūyate: vitti + anubhūyate (wealth is enjoyed)

ekasataṃ khatyā (one hundred and one men of ruling caste): khattiyā

ratyo: rattiyo (nights)

ratyā: rattiyā (by night)

ratyaṃ: rattiyaṃ (in the night)

sakvāhaṃ mārisa devānamindo, iccādi. (sir, I am the sakka, who is the king of deites, and so on): Sakko + ahaṃ ⇒ sakkvahaṁ ⇒ sakvāhaṁ

- - - - - **sarūpānanti kiṃ? titthyā puthuso vadanti, catutthyantaṃ, chaṭṭhuntaṃ, cakkhvābādhaṃ, vatthvettha. iti byañjanaloparāsi.**

Why is the term 'sarūpānaṃ' there? (when three dissimilar consonants, no elision occurs)

Ti**tthy**ā puthuso vadanti (people of other sects diversely say): Ti**tth**iyā

catu**tthy**antaṃ: catuṭṭhī + antaṃ (a term ending with da ve case)

cha**ṭṭhy**antaṃ: chaṭṭhī + antaṃ (a term ending with genitive case)

in burmese scripts it is wrongly given as chaṭṭhy**un**taṁ

ca**kkhv**ābādhaṃ: cakkhu + ābādhaṃ (disease of the eye)

va**tthv**ettha (here, the land): Vatthu + ettha

- - - - - **Iti byañjanaloparāsi.**

This is the collection of elision of consonants.

pupphaṁ → utu, rajo, menstruation

utunī ↔ a menstruating woman

āhita \[ā + √dhā + ita\] → pp. stocked up; heaped up; provided with fuel; lit. placed here 2; pp. put in, put up

#### **bindulopa

**31\. lopo** (elision of niggahīta)

**Niggahītassa kvaci lopo hoti vā.**

In some places, elision of niggahīta happens alternatively. (not compulsory)

**Sare pare tāva** -

First, when a vowel is succeeding (following are the examples) -

**evāhaṃ cintayitvāna**

(evaṃ + ahaṃ ⇒ eva ahaṁ (lopo) ⇒ avāhaṁ)

I, having thought like this

**pupphadānaṃ adāsahaṃ - adāsiṃ + ahanti chedo, bindulopo, puna pubbasaralopo**

(adāsiṃ + ahaṃ ⇒ adāsi ahaṁ ⇒ adāsahaṁ)

I offered (made) a flower offering. Separation should be done as adāsiṃ + ahaṃ, elision of the niggagīta happens, Again, elision of the preceeding vowel happens

**Tuyhatthāya mahāmuni**

(tuyhaṃ + atthāya (lopo) ⇒ tuyha atthāya (saro lopo sare) ⇒ tuyh atthāya)

O great sage, for your benefit

**tuyhevetaṃ dukkaṭaṃ**

(tuyhaṃ + eva \[lopo\] ⇒ tuyha eva \[saro lopo sare\] ⇒ tuyh eva)

This is indeed your fault

**Tāsāhaṃ santike**

(tāsaṃ + ahaṃ \[lopo\] ⇒ tāsa ahaṁ \[paro lopo sare\] ⇒ tās ahaṁ \[dīgha\])

I, in the vicinity of them (fem.)

**tesāhaṃ evaṃ vadāmi**

(tesaṃ + ahaṃ)

I tell them thus.

**Pañcannetaṃ dhammānaṃ adhivacanaṃ**

(pañcannaṃ + etaṃ)

This is a name of those five natures

vocab: #\[\[**pāḷi** vocab (2nd year)\]\]

adhivacana ↔ nāma, saññā, ākhyā, abhilāpa, abhidhāna, samaññā

ākhyā → nāma, saññā, , abhilāpa, abhidhāna, samaññā, adhivacana

**Channetaṃ dhammānaṃ adhivacanaṃ**

(channaṃ + etaṃ)

This is a name of those six natures

**Samaṇa tveva pucchāmi**

(tvaṃ + eva)

O monk, I ask you indeed

**Brāhmaṇa tveva pucchāmi** - **tvaṃ+evāti chedo**,

(tvaṃ + eva)

O brahmin, I ask you indeed. Separation should be done as tvaṃ + eva.

**Vidūnaggamiti**.

(vidūnaṃ + aggamiti)

Great among the wise ones

**Byañjane pare -**

When a consonant is succeeding (following are the examples)

**taṃ tuyhamūle paṭidesemi**.

(tuyhaṃ + mūle)

I confess it in the vicinity of you

**note**: with a gap "tuyha mūle" is also correct because the preceding letter is a vowel and does not need to be attached while in loka aggo ⇒ lok aggo - there is the need for attaching them because 'k' has no vowel

**Gāthāyaṃ** - In gāthā (following are the examples)

**ariyasaccāna dassanaṃ**

(ariyasaccānaṃ + dassanaṃ)

Seeing the noble truths

**etaṃ buddhāna sāsanaṃ**

(buddhānaṃ + sāsanaṃ)

This is the admonishment of the Buddhas.

**Khandhānañca paṭipāṭi, dhātuāyatanāna ca.**

(dhātuāyatanānaṃ + ca)

The order of khandha, āyatana and dhātu

vocab: #\[\[**pāḷi** vocab (2nd year)\]\]

paṭipāṭi \[pati + √paṭ + \*i\] fem. → turn (in queue); order; chance 2 fem. sequence; succession; series

**māgame pare -**

When inserted 'm' is succeeding (following are the examples)

**garuḷo uragāmiva**

(uragaṃ + iva ⇒ uragaṁ miva (āgama sandhi) ⇒ uraga miva)

As a garuḍa (catches) a snake

**dhammo arahatāmiva**

(arahataṃ + iva ⇒ arahataṁ miva ⇒ arahata miva ⇒ arahatā miva)

As dhamma (is pleasing) to the arahants

**āloko passatāmiva**

(passataṃ + iva)

As light, (Nibbāna becomes clear), for the ones who see (with insight)

**bako kakkaṭakāmiva**

(kakkaṭakaṃ + iva)

As a crane, crab

**nabhaṃ tāmiva**

(tārakitaṃ + iva)

As the sky with stars

**padumaṃ hatthagatāmiva** **\- etesu māgame bindulopo, byañjane pubbasaradīgho ca.**

(hatthagataṃ + iva)

As a lotus that is in (that is rubbed by) one's hand.

In these examples, niggahita is dropped when 'm' is inserted. And the preceeding vowel is lengthened when a consonant is succeeding.

**Tathā saṃupasaggassa bindulope antasaradīgho** -

Apart from that, when the niggahīta of prefix 'saṃ' is dropped, its ending vowel is lengthened.

**Sārāgo**

(saṃ + rāgo)

Extreme lust

**sāratto**

(saṃ + ratto)

one who is extremely impassioned.

**avisāhāro**

(avisaṃ + hāro)

That which does not carry the mental factors here and there.

**sārambho**

(saṃ + rambho)

Intense heat

**sāraddho**

(saṃ + raddho)

That which is intensely heat

**sāketaṃ nagaraṃ**

(saṃ + keta)

**sādhāraṇaṃ**

(saṃ + dhāraṇaṃ)

That which has a similar holding; common

**saṃ assa atthīti sāmī.**

(saṃ + āmī)

One who has property is called sāmī

**Samāse tumantamhi niccaṃ** -

In samāsa, bindulopa always happens in the term ending with 'tuṃ' suffix.

**kattukāmo, gantukāmo iccādi.**

(kattuṃ + kāmo, gantuṃ + kāmo)

The one who likes to do, the one who likes to go etc.

**iti binduloparāsi.**

This is the collection of the elision of niggahita.

- **notes**
  - in every sutta there are **3 parts**
    - **the sutta**: the rule
      - characteristics of a sutta
        - **appakkharaṁ** (few letters): it should be as concise as possible
    - **vutti**: the description
    - **udāharaṇa**: the example
  - 3 **vutti**
    - suttavutti: what is mentioned in the sutta
    - anuvattanavutti: what is not mentioned in the sutta
    - pakkhipanavutti: what is added by the grammarian to explain
  - isn't gacchanto - that can be use to refer to another noun - a pronoun? no, it is a kitaka noun, pronouns are not made out of root, suffix, etc.

      a.className = "toc-h2-link";
      
      // Container for H3 items (to be filled later)
      const h3Container = document.createElement("ul");
      h3Container.className = "toc-h3-list";
	h3Container.classList.add("collapsed");
      
	// Assemble
      li.appendChild(toggle);
      li.appendChild(a);
      li.appendChild(h3Container);
      tocList.appendChild(li);
      
      // Store references
      currentH2Item = li;
      currentH3List = h3Container;
      
      // Add click toggle functionality
      const toggleSection = () => {
        const isCollapsed = h3Container.classList.contains("collapsed");
        if (isCollapsed) {
          h3Container.classList.remove("collapsed");
          toggle.textContent = "▼";
          toggle.setAttribute("aria-label", "Collapse section");
        } else {
          h3Container.classList.add("collapsed");
          toggle.textContent = "▶";
          toggle.setAttribute("aria-label", "Expand section");
        }
      };
      
      toggle.addEventListener("click", function(e) {
        e.preventDefault();
        e.stopPropagation();
        toggleSection();
      });
      
      a.addEventListener("click", function(e) {
        // Allow normal anchor behavior, but also toggle if desired?
        // Comment out the next line if you want clicking the link to ALSO toggle
        // e.preventDefault(); 
        // Uncomment below to toggle when clicking the link text too
        // toggleSection();
        // Then scroll to heading
        // document.getElementById(heading.id).scrollIntoView({ behavior: "smooth" });
      });
      
    } else if (heading.tagName === "H3" && currentH3List) {
      // Add H3 item under current H2
      const li = document.createElement("li");
      const a = document.createElement("a");
      a.href = `#${heading.id}`;
      a.textContent = heading.textContent;
      li.appendChild(a);
      currentH3List.appendChild(li);
    }
  });
  
  // Insert TOC at the beginning of the page
  const firstHeading = document.querySelector("h1, h2");
  if (firstHeading) {
    firstHeading.parentNode.insertBefore(toc, firstHeading);
  } else {
    document.body.insertBefore(toc, document.body.firstChild);
  }
});
