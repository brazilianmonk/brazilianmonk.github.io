## Meanings of dutiyā vibhatti



-   **kammattha** (object meaning)
    -   puriso gāmaṃ gacchati
-   **kammappavacanīyattha** (combination)
    -   rukkhamabhi vijjotate vijju (lightning flashes upon the tree)
-   **kriyāvisesanattha** (adverbial meaning)
    -   sukhaṁ supati, sukhaṃ paṭibujjhati (he sleeps comfortably; he wakes up comfortably)
-   **accantasaṁyogattha**: meaning of continuous association
    -   māsaṃ maṃsodanaṃ bhuñjati (he eats rice with meat for a whole month)
-   **aññāvibhattiyattha / vibhattivipallāsa**: used with certain particles, prefixes, nouns, and verbs 
    -   paṭibhantu *taṃ* cunda bojjhaṅgā (let the factors of enlightenment occur to you, cunda)
    -   **kāraṇattha**
        -   kiṃ kāraṇaṃ? (for what reason?)
-   notes:
    -   dutiyāvibhatti is used to express these atthas when they are not vutta by the verb
        -   purisena gāmo gacchīyate
            -   gāmo: in the paṭhamāvibhatti expressing liṅgattha because the kammattha is expressed by the verb termination

### kammattha &#x2013; definition


**karīyatīti kammaṃ**: that which the action is performed upon, directed toward

-   puriso gāmaṃ gacchati
    -   gāmaṁ: kammattha because gacchati acts toward gāma
    -   gacchati: action of going performed toward the object gāma



-   9 types of kamma (4 groups)

    
    
    -   3 
        -   **nibbatti kamma**
        -   **vikati kamma**
        -   **patti kamma**
    -   2
        -   **pakati kamma**
        -   **vikati kamma**
    -   related to verbs
        -   2
            -   **dhātu kamma**
            -   **kārita / payojja kamma**
        -   2
            -   **padhāna kamma** (primary object)
            -   **appadhāna kamma** (secondary object)
    -   mem aid:
        -   kamma (object) -> meditation object -> paṭibhāganimitta (produced, expanded, attained) -> gold (natural, transformed) -> action (root, causative) -> dvikammakadhātus (primary, secondary)
    
     
    
    -   nibbatti, vikati, and patti kamma
    
        
        
        -   **nibbatti kamma** (produced object): what is produced, built, given birth, made, expounded, made to arise
            -   āhāro sukhaṃ janayati (food produces comfort)
            -   rājā nagaraṃ māpeti
            -   mātā puttaṃ vijāyati
            -   jano puññaṃ karoti
            -   buddho dhammaṃ desesi
            -   bhikkhu jhānaṃ uppādeti
        -   **vikati kamma** (transformed object): what is transformed, made into something else
            -   kaṭṭhaṃ aṅgāraṃ karoti (he transforms wood into charcoal; he makes charcoal from wood)
                -   kaṭṭhaṁ: pakatikamma
                -   aṅgāraṁ: vikatikamma
            -   suvaṇṇaṃ kaṭakaṃ karoti (he transforms gold into a bracelet; he makes a bracelet from gold)
                -   suvaṇṇaṁ is pakatikamma
                -   kaṭakaṁ is vikatikamma
        -   **patti kamma** (reached object): what is arrived / attained / reached, including mentally in acts such as seeing or paying respect
            -   nivesanaṃ pavisati (he enters the house)
            -   gāmaṃ gacchati (he goes to the village)
            -   ādiccaṃ passati (he sees the sun)
            -   dhammaṃ suṇāti (he hears the dhamma)
            -   buddhaṃ vandati (he worships the Buddha)
        
        **nibbattivikatippatti-bhedena tividhaṃ mataṃ
        kattukriyābhigammaṃ taṃ, sukhaṅgāraṃ nivesanaṃ** (rpsd)
        that object attained through the action of the agent is threefold,
        nibbatti, vikati, and patti; sukha, aṅgāra, and nivesana (are examples)
        
        -   kamma is attained through the action of the agent (kattukriya)
        
        
    
    -   pakati and vikati kamma
    
        
        
        -   **pakati kamma** (natural object): an object that exists in its original state
        -   **vikati kamma** (modified object): an object that undergoes modification
        
        so suvaṇṇaṃ kaṭakaṃ karoti
        
        -   suvaṇṇaṁ: pakatikamma
        -   kaṭaka: vikatikamma
        
        
    
    -   dhātu and kārita kamma
    
        
        
        -   **dhātu kamma** (object of the root): object governed directly by the verbal root (dhātu)
            -   gāmaṃ gacchati
                -   gāmaṃ: object of the root gam
                -   (*:q: why "governed"?*)
        -   **kārita / payojja kamma** (causative object): object related to the kārita paccaya (causative suffix: ṇe, ṇaya, ṇāpe, ṇāpaya) &#x2013; can be in dutiyā, tatiyā, or chaṭṭhī vibhatti
            -   so purisaṃ / purisena / purisassa gāmaṃ gāmeti (he causes the man to go to the village)
                -   so: kārita kattu (causative agent) since it causes the action of going
                -   purisa
                    -   if regarded as kāritakamma of ṇe for being caused to go &#x2013; dutiyāvibhatti or chaṭṭhīvibhatti (rare)
                        -   therassa patto dutiyassa gāhetabbo (the elder’s bowl should be made to be taken by the second monk)
                    -   if regarded as dhātukattu of √gam for actually going &#x2013; tatiyāvibhatti
                -   gāmaṃ: dhātukamma of √gam since it is what receives the action of going
                -   gameti: √gam + ṇe
        
                
    
    -   padhāna and appadhāna kamma &#x2013; dvikammakadhātus and their kammas
    
        
        **dvikammaka dhātu** (ditransitive roots): root that require 2 objects, which are expressed in dutiyāvibhatti &#x2013; √nī, √har, √vah, √yāc, √pucch
        
        2 kammas of dvikammakadhātus:
        
        -   **padhāna / kathita / kathina kamma** (primary- / mentioned- / firm- object)
            -   nrtdpn: kathina (firm) because it is always in dutiyāvibhatti
        -   **appadhāna / akathita / akathina kamma** (secondary- / non-mentioned- / non-firm- object)
            -   nrtdpn: akathina (non-firm) because it is not always in dutiyāvibhatti
                -   akathita doesn't make sense since both are mentioned
                -   gopālo gāviṁ khīraṁ duhati -> gopālo gāvito khīraṁ duhati
                    -   khīraṁ: padhānakamma
                    -   gāviṁ: apadhānakamma, can be expressed as gāvito
                -   bhante: but if so, it is not kamma anymore
        
        
        
        -   √nī &#x2013; ajapālo ajaṃ gāmaṃ neti (the goatherd leads the goat to the village)
            -   ajaṁ: padhānakamma since it is what is led
            -   gāmaṁ: appadhānakamma since it is where it is led to
        -   √har &#x2013; rājapuriso coraṁ bhaṇḍanāgāraṁ harati
        -   √vah &#x2013; (*:q: find example*)
        -   √yāc &#x2013; ahaṁ ābhaddharaṁ pothakaṁ yācāmi
        -   √pucch &#x2013; devo buddhaṁ pañhaṁ pucchati
        -   notes:
            -   normally, the padhānakamma is placed first
            -   in passive voice: one of them should be in paṭhamāvibhatti (to be studied later)

### kammappavacanīya


**kammaṃ pavuttavanto’ti kammappavacanīyā**: words called so because they express an action-related meaning in cases other than this

-   kamma: action
-   pavuttavanto (pa √vac tavantu)
-   kammappavacanīya: those that expressed an action in the past (pavuttavanto)
    -   ptp. should be called; should be said; lit. to be stated (pa + √vac + anīya)

the upasaggas **abhi / pari / pati / anu** (and upa in hīna) can express action-related meanings and non-action-related meanings

-   when expressing action-related meanings, they are called upasaggas
    -   abhi: facing, surpassing
    -   anu: following
-   when expressing non-action-related meanings, they are called kammappavacanīya and the associated word is in dutiyāvibhatti



-   6 meanings of kammappavacanīya

    
    
    -   **lakkhaṇa** (sign, mark, indicator): something that helps recognize, indicate an object
    -   **itthambhūta** (state or condition): having arrived at a certain state or condition
    -   **vicchā** (distribution)
    -   **bhāga** (portion, share)
        -   except abhi
    -   **hīna** (inferiority)
    -   **saha** (association)

    -   lakkhaṇa kammappavacanīya
    
        
        **lakkhaṇa kammappavacanīya** (sign, mark, indicator): something that helps recognize, indicate an object
        
        -   e.g.:
            -   *rukkhamabhi* vijjotate vijju
                *rukkhaṃ pati* vijjotate vijju
                *rukkhaṃ pari* vijjotate vijju
                *rukkhamanu* vijjotate vijju
                (the "light of the lightning" shines upon the tree)
                -   rukkhaṁ: dutiyāvibhatti with ādhārattha
                -   abhi / pati / pari / anu: lakkhaṇa kammappavacanīya
                    -   the lightning is recognized by the illumination of the tree so the tree serves as the indicator (lakkhaṇa) by which the lightning is known
            -   tato ratyā vyavasāne, *suriyassuggamanaṃ pati* dibbā bhakkhā pātubhaveyyuṃ, sīlavantā ca yācakā (then, at the end of the night, at the time of the sun’s rising, may divine food appear, and may virtuous mendicants also come (so that i may offer it to them))
                -   suriyassuggamanaṃ: at sunrise
                -   pati: lakkhaṇa kammappavacanīya marking that time
                    -   it is equivalent to suriyassuggamane
            -   *pabbajitamanu* pabbajiṃsu (when (the bodhisatta) went forth, many others also went forth)
                -   pabbajitaṁ: dutiyāvibhatti
                    -   normally, pabbajite (bhāvalakkhaṇa)
                -   anu: lakkhaṇa kammappavacanīya
            -   note: it can act in the place of bhāvalakkhaṇa in some cases
        
            
    
    -   itthambhūta kammappavacanīya
    
        
        **itthambhūta** (state or condition): having arrived at a certain state or condition
        
        -   e.g.:
            -   sādhu devadatto mātaramabhi / pati / pari / anu (devadatta has become good with regard to his mother)
                -   devadatta attained a specific condition (being good) towards his mother, not towards others
            -   taṃ kho pana bhavantaṃ gotamaṃ evaṃ kalyāṇo kittisaddo abbhuggato
                -   taṃ kho pana bhavantaṃ gotamaṃ: dutiyāvibhatti
                    -   normally, tassa bhoto gotamassa kittisaddo
                -   abhi in abbhuggato: itthambhūta
                -   uggato: has risen up, spread about
                -   because the reputation arose, the blessed one became a person endowed with reputation (state)
        
        
    
    -   vicchā kammappavacanīya
    
        
        **vicchā** (distribution, extension, spreading): see sandhi chapter 
        
        -   rukkhaṃ rukkhaṃ abhi / pati / pari / anu vijjotate cando (the moon shines over each and every tree)
            -   rukkhaṁ rukkhaṁ: dutiyāvibhatti in the locative meaning
                -   normally, rukkhe rukkhe (over each and every tree) is expected
        
              
    
    -   bhāga kammappavacanīya
    
        
        **bhāga** (portion, share)
        
        -   yadettha maṃ pati / pari / anu siyā taṃ dīyatu (whatever portion here is mine (for me), let that be given)
            -   maṁ: dutiyā due to the kammappavacanīya
                -   normally, genitive mamaṁ, etc. would be used
            -   pati / pari / anu: indicates a share set aside for someone
                -   abhi is not used in bhāga meaning
        
        
    
    -   hīna kammappavacanīya
    
        
        **hīna** (inferiority)
        
        -   anu sāriputtaṃ paññavanto (all the wise ones are inferior to Elder Sāriputta)
        -   upa sāriputtaṃ paññavanto (all the wise ones are inferior to Elder Sāriputta)
            -   normally, the apādāna sāriputtasmā (than Sāriputta) is expected
            -   (*:q: upa is not included in other places*)
            -   (*:q: can abhi / pati / pari be used here?*)
        
         
    
    -   saha kammappavacanīya
    
        
        **saha** (association):
        
        -   nadī pabbataṃ anu tiṭṭhati (the river stands together with, attached to the mountain)
            -   normally, the instrumental pabbatena (together with the mountain) is expected
            -   (*:q: can abhi / pati / pari be used here?*)

### kriyā visesana / bhāvanapuṁsaka &#x2013; definition


**kriyā visesana** (action modifier): expresses the manner in which an action is performed

-   comm: bhāvanapuṃsaka (action-referring neuter-like term): a word which refers to an action (bhāva) and looks like a neuter-gender word (napuṁsaka)
-   sukhaṃ supati (he sleeps comfortably)
-   sukhaṃ paṭibujjhati (he wakes up comfortably)
-   dukkhaṃ seti parājito (the defeated one lies down miserably)
-   sīghaṃ gacchati (he goes quickly)
-   dandhaṃ gacchati (he goes slowly)
-   muduṃ pacati (he cooks gently)
-   sannidhikārakaṃ bhuñjeyya (if one eats having stored)
    -   can also be the food itself as kammattha (if one eats stored food)
-   kāyappacālakaṃ gacchati (he walks shaking his body)
-   bāhuppacālakaṃ gacchati (he walks swinging his arms)
-   surusurukārakaṃ bhuñjati (he eats making a slurping sound)
-   piṇḍukkhepakaṃ bhuñjati (he eats throwing lumps of food)
-   hatthaniddhunakaṃ bhuñjati (he eats shaking his hands)
-   hatthanillehakaṃ bhuñjati (he eats licking his hands)
-   note: there are no suttas in traditional grammar for adverbs because they are included under objects
    -   but in sdnt: bhāvanapuṁsake dutiye vacanaṁ

### accantasaṃyoga &#x2013; definition


**kālassa vā addhuno vā dabbaguṇakriyāhi accantaṃ nirantaraṃ saṃyogo accantasamyogo**: uninterrupted association with or application of a substance (dabba), quality (guṇa), or action (kiriyā) over a period of time (kāla) or distance (addha)

-   ati anta: to the end
-   saṁyoga: association, application



-   2 types

    
    
    -   **kāla accantasaṃyoga** (time continuity)
        -   dabba
            -   māsaṃ maṃsodanaṃ bhuñjati (he eats meat-mixed rice for a whole month)
        -   guṇa
            -   saraddaṃ ramaṇīyā nadī (the river is beautiful throughout the autumn season)
        -   kriyā
            -   māsaṃ sajjhāyati (he recites for a month)
            -   yo ca vassasataṃ jīve (whoever lives for a hundred years)
            -   tayo māse abhidhammaṃ desesi (he taught the abhidhamma for three months)
            -   sattāhaṃ ekapallaṅkena nisīdati (he sits in one posture for seven days)
    -   **addhā accantasamyoga** (distance continuity) 
        -   dabba
            -   yojanaṃ vanarāji (a forest stretching throughout a yojana)
        -   guṇa
            -   yojanaṃ dīgho pabbato (a mountain one yojana long)
        -   kriyā
            -   yojanaṃ dhāvati (he runs for a yojana)
            -   kosaṃ sajjhāyati (he recites for a distance of one kosa)
                -   500 dhanu = kosa (dhanu pañcasataṁ koso)

### aññavibhattiyattha



-   (related to kammappavacanīya)
    -   **vicchāttha** (spreading, expanding)
    -   **bhāgattha** (portion, share)
    -   **hīnattha** (inferiority)
    -   **sahattha** (association)
-   **karaṇattha**: with **antarena / vinā** (having excluded / without)
    -   na upāyamantarena atthassa siddhi (there is no accomplishment of an aim (success) without a means)
    -   vinā saddhammaṃ kuto sukhaṃ (without the dhamma, where is happiness?)
-   **sampadānattha**: with **paṭibhāti** (to be clear / to occur to)
    -   paṭibhantu *taṃ* cunda bojjhaṅgā (cunda, may the factors of enlightenment become clear, occur to you)
    -   paṭibhāti *maṃ* bhagavā (the blessed one! it becomes clear to me; it occurs to me)
    -   *maṃ* tisso upamā paṭibhaṃsu (three similes occurred to me)
-   **sambandhattha** with
    -   **dhī**: condemnation, reproach
        -   dhī brāhmaṇassa *hantāraṃ* (shame on (of) the killer of the bramin, and arahant -> i condemn the killer of the brahmin)
            -   hantāraṃ (the killer): dutiyā in genitive meaning
        -   dhī *cittaṃ*, dhī *cittaṃ* (i condemn the mind! fie upon the mind! fie upon the mind!)
        -   dhīratthu *taṃ dhanalābhaṃ*, *yasalābhañca* brāhmaṇa (fie upon that gain of wealth and gain of fame, o brahmin!)
        -   dhīratthu *bahuke kāme* (fie upon the many sensual pleasures!)
            -   along with the particle dhī, in addition to the accusative case, the instrumental case is also used
                -   dhīratthu jīvitena me (fie upon my life!)
        -   rpsd: dhī is also regarded as kammappavacanīya, but mgln
            -   dhī brāhmaṇassa hantāraṃ
    -   place from where directions are given such as **pubba (east), dakkhiṇa (south), and uttara (north)**:
        -   pubbena *gāmaṃ* (to the east of the village)
    -   **antarā**: between
        -   antarā ca *rājagahaṃ* antarā ca *nāḷandaṃ* (between (of) the city of Rājagaha and (of) the city of Nāḷanda)
    -   **abhito (near), parito (around), and pati**
        -   abhito / parito *gāmaṃ* vasati (he lives near / around the village)
        -   *nadiṃ nerañjaraṃ* pati (near the river nerañjarā)
-   **ādhārattha** (location)
    -   in **time-denoting words** (ekaṁ samayaṁ, pubbāṇhasamayaṁ, imaṁ rattiṁ, taṁ khaṇaṁ, tato paraṁ)
        -   *ekaṃ samayaṃ* bhagavā sāvatthiyaṃ viharati (at one time, the blessed one was dwelling at sāvatthī)
        -   *pubbāṇhasamayaṃ* nivāsetvā piṇḍāya pāvisi (in the morning time, having dressed, he entered for alms)
        -   *imaṃ* bhikkhave *rattiṃ* cattāro mahārājā yena ahaṃ tenupasaṅkamiṃsu (on this night, monks, the four great kings approached me)
        -   *taṃ khaṇaṃ* (at that moment)
        -   tato *paraṃ* (after that)
    -   in **direction-denoting words** (ekamantaṁ, purimaṁ disaṁ)
        -   *ekamantaṃ* aṭṭhāsi (he stood on one side)
            -   ekamantaṃ: also regarded as accusative in the adverbial meaning
        -   *purimaṃ disaṃ* dhatarattho … kuvero *uttaraṃ disaṃ* (aṭṭhāsi) (dhatarattha stood in the eastern direction; kuvera in the northern direction)
    -   location of **prefixed akammaka dhātu** (intransitive verbal roots)
        -   aciraṃ vata’yaṃ kāyo *paṭhaviṃ* adhisessati (indeed, before long, this body will lie upon the earth)
        -   *agāraṃ* ajjhāvasati (he lives in a house; household life)
        -   *mañcaṃ* vā *pīṭhaṃ* vā abhinisīdeyya vā abhinipajjeyya vā (he may sit or lie down on a bed or a chair)
        -   *kāmāvacaraṃ bhūmiṃ* upapajjati (he is reborn in the sensual realm)
    -   location of **pivati and carati** 
        -   *nadiṃ* pivati (he drinks in the river)
        -   *gāmaṃ* carati (he moves about in the village)
            -   when carati means wandering it doesnt have an object; gāmaṁ here means the place where one wanders, not the destination
            -   when it means practice "dhammaṁ carati" it has an object

  const toc = document.createElement("div");
  toc.className = "table-of-contents";
  toc.innerHTML = "<h2>📖</h2><ul></ul>";
  const tocList = toc.querySelector("ul");
  
  let currentH2Item = null;
  let currentH3List = null;
  
  headings.forEach(heading => {
    if (heading.closest(".table-of-contents")) return;
    
    if (!heading.id) {
      heading.id = heading.textContent
        .toLowerCase()
        .replace(/[🇧🇷🇪🇸🇬🇧]/g, "")
        .replace(/[^\w\s-]/g, "")
        .replace(/\s+/g, "-");
    }
    
    if (heading.tagName === "H2") {
      // Create container for this H2 section
      const li = document.createElement("li");
      li.className = "toc-h2-item";
      
      // Add toggle arrow
      const toggle = document.createElement("span");
      toggle.className = "toc-toggle";
	toggle.textContent = "▶";  // Collapsed by default
      toggle.setAttribute("aria-label", "Collapse section");
      
      // Add the H2 link
      const a = document.createElement("a");
      a.href = `#${heading.id}`;
      a.textContent = heading.textContent;
      a.className = "toc-h2-link";
      
      // Container for H3 items (to be filled later)
      const h3Container = document.createElement("ul");
      h3Container.className = "toc-h3-list";
	h3Container.classList.add("collapsed");
      
	// Assemble
      li.appendChild(toggle);
      li.appendChild(a);
      li.appendChild(h3Container);
      tocList.appendChild(li);
      
      // Store references
      currentH2Item = li;
      currentH3List = h3Container;
      
      // Add click toggle functionality
      const toggleSection = () => {
        const isCollapsed = h3Container.classList.contains("collapsed");
        if (isCollapsed) {
          h3Container.classList.remove("collapsed");
          toggle.textContent = "▼";
          toggle.setAttribute("aria-label", "Collapse section");
        } else {
          h3Container.classList.add("collapsed");
          toggle.textContent = "▶";
          toggle.setAttribute("aria-label", "Expand section");
        }
      };
      
      toggle.addEventListener("click", function(e) {
        e.preventDefault();
        e.stopPropagation();
        toggleSection();
      });
      
      a.addEventListener("click", function(e) {
        // Allow normal anchor behavior, but also toggle if desired?
        // Comment out the next line if you want clicking the link to ALSO toggle
        // e.preventDefault(); 
        // Uncomment below to toggle when clicking the link text too
        // toggleSection();
        // Then scroll to heading
        // document.getElementById(heading.id).scrollIntoView({ behavior: "smooth" });
      });
      
    } else if (heading.tagName === "H3" && currentH3List) {
      // Add H3 item under current H2
      const li = document.createElement("li");
      const a = document.createElement("a");
      a.href = `#${heading.id}`;
      a.textContent = heading.textContent;
      li.appendChild(a);
      currentH3List.appendChild(li);
    }
  });
  
  // Insert TOC at the beginning of the page
  const firstHeading = document.querySelector("h1, h2");
  if (firstHeading) {
    firstHeading.parentNode.insertBefore(toc, firstHeading);
  } else {
    document.body.insertBefore(toc, document.body.firstChild);
  }
});
</script>
