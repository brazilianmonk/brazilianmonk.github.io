## Meanings of chaṭṭhī vibhatti



-   **sambandhattha** (relation, possession, connection): relationship; that with which there is a connection or relation
    -   rañño puriso
    -   devānaṃ indo (the king of deities)
-   **aññavibhattiyattha**
    -   **kammattha**
        -   pāpānaṃ akaraṇaṃ sukhaṃ
        -   bhagavā amatassa dātā (the blessed one who gives the deathless)
    -   **kattvattha**
        -   purisassa kataṃ
    -   **karaṇattha**
        -   pupphassa buddhaṃ yajati
        -   pūrati bālo pāpassa
        -   imameva kāyaṃ pūraṃ nānappakārassa asucino paccavekkhati
    -   **apādānattha**
        -   sabbe tasanti daṇḍassa, sabbe bhāyanti maccuno
    -   **kāraṇattha**
    -   **ādhārattha**
    -   **niddhāraṇattha**
        -   āyasmā ānando arahataṃ aññataro ahosi
    -   **bhāvalakkhaṇattha**
        -   aññatarassa bhikkhuno passāvaṃ karontassa asuci mucci
    -   **anādarattha**
    -   with **sāmi, issara, etc**

### sambandhattha &#x2013; definition and 2 types


**sambandha**: relation, connection, belonging that exists between two things

-   **visesa sambandha / sambandha**: qualifying relational word; expressed in the chaṭṭhīvibhatti
-   **visesya sambandha / sambandhī**: qualified relational word; that which *has* a relation
    -   can express multiple meanings (see below)
-   note: akāraka attha since it does not produce an action

devānaṃ indo (the king of the deities)

-   relationship of possession between:
    -   devānaṁ: inhabitants of that king’s heavenly realm &#x2013; sambandha
    -   indo: king of deities &#x2013; sambandhī



-   12 types of sambandha

    
    
    -   **sāmi** sambandha (master-relationship)
        -   devānaṃ indo
    -   **sevaka** sambandha (servant-relationship) 
        -   rañño puriso (the king’s man)
    -   **bhaṇḍa** sambandha / **saṁ** sambandha (property-relationship)
        -   saṁ: property, wealth
        -   bhikkhussa pattacīvaraṃ (the monk’s bowl and robe)
    -   **samīpa** sambandha (proximity-relationship) 
        -   nibbānassa santike (near Nibbāna)
    -   **samūha** sambandha (collective-relationship) 
        -   bhikkhūnaṃ samūho (the group of monks)
    -   **avayava** sambandha (part-relationship) 
        -   rukkhassa sākhā (the branch of the tree)
    -   **vikāra** sambandha (modification relationship)
        -   dhaññānaṃ sattu (flour of grains)
    -   **kāriya** sambandha (result-relationship) 
        -   kammānaṃ vipāko (the result of actions)
    -   **avatthā** sambandha (state-relationship) 
        -   khandhānaṃ pātubhāvo (the arising of the aggregates)
    -   **guṇa** sambandha (quality-relationship) 
        -   buddhassa guṇā (the qualities of the Buddha)
        -   rūpassa lahutā (the lightness of form)
        -   pupphānaṃ gandho (the fragrance of flowers)
    -   **kriyā** sambandha (action-relationship) 
        -   pādassa ukkhipanaṃ (the lifting of the foot)
    -   **kula** sambandha (family-relationship) 
        -   tassa bhātā (his brother)

### aññavibhattiyattha



-   **kammattha**
    -   kamma of certain **kitakas**
        -   **-aka** 
            -   kammassa **kārako** natthi, vipākassa ca **vedako** (there is no doer of action, nor experiencer of its result)
        -   **-ana** 
            -   pāpānaṃ **akaraṇaṃ** sukhaṃ (the non-doing of evil is happiness)
            -   sabbapāpassa **akaraṇaṃ** (not doing all the evil)
            -   aññatarassa vā aññatarassa vā aṅgassa **parāmasanaṃ** (the touching of one body part or another)
        -   **-āvī** 
            -   ādīnavassa **dassāvī** (a seer of danger)
        -   **-ṇa** 
            -   hatthassa **gāho** (the grasping of the hand)
            -   vatthānaṃ **rāgo** (the dyeing of cloths)
        -   **-ṇī** 
            -   jhānassa **lābhī** (a possessor of jhāna)
        -   **-tu** 
            -   Bhagavā amatassa **dātā** (The Blessed One, the giver of the deathless)
        -   **-tvā** 
            -   āyasmato **nissāya** vacchāmi (i will dwell depending on the venerable sir)
        -   mem aid: akānāvīṇaṇītutvā
    -   kamma of **√sar** (to remember) and **√icch** (to desire)
        -   mātu / mātaraṁ **sarati** (he remembers (his) mother)
        -   na tesaṃ koci **sarati** (no one remembers them)
        -   sā puttassa **icchati** (she desires a son)
            -   or puttaṁ icchati
-   **kattvattha**
-   **karaṇattha** 
    -   verbs meaning "**to honor**": √yaj, √man, √cāy, √pūj, √vand
        -   pupphassa buddhaṃ **yajati** (he honours the Buddha with flowers)
    -   roots meaning "**to fill**": √pūr 
        -   **pūrati** bālo pāpassa (the fool fills (himself) with evil)
        -   imameva kāyaṃ **pūraṃ** nānappakārassa asucino (this very body filled with various kinds of impurity)
    -   agent of certain **kitakas**: 
        -   rañño **pūjito** (honoured by the king)
            -   or rājena
        -   amataṃ tesaṃ bhikkhave **aparibhuttaṃ**, yesaṃ kāyagatāsati **aparibhuttā** (bhikkhus, those by whom mindfulness directed to the body is not developed, by them the deathless is not experienced)
-   **apādānattha**
    -   verbs meaning **“to decline”**: √hā
        -   dhammassa **parihāyanti** (they decline from the Dhamma)
    -   verbs meaning **“to fear”**: √tas, √bhī
        -   sabbe **tasanti** daṇḍassa (all tremble from (at) punishment)
        -   sabbe **bhāyanti** maccuno (all fear death)
-   **kāraṇattha**
-   shared with sattamī
    -   **ādhārattha**: with **kusala** (skilled), **pasanna** (faithful)
        -   **kusalā** naccagītassa (women skilled in dancing and singing)
        -   amanussā bhagavato **pasannā** (non-human beings who has faith in the Blessed One)
    -   **niddhāraṇattha** (selection) 
        -   appakā te manussesu, ye janā pāragāmino (among human beings, those people who go to the far shore are few)
    -   **bhāvalakkhaṇattha** (temporal marking with an action) 
        -   bodhisatte jāyamāne dasasahassilokadhātu saṅkampi (when the bodhisatta was being born, the ten-thousand world system trembled)
    -   **anādarattha** (disregard) 
        -   so mātāpitunnaṃ rudantānaṃ / rudantesu pabbaji (he went forth into homelessness while his parents were weeping)
    -   with **sāmi** (owner), **issara** (lord), etc
        -   gunnaṃ sāmi / gosu sāmi (the owner of the cattle)

### extra notes

-   irregular futures

    -   **vacchāmi**: i will dwell
        -   āyasmato nissāya vacchāmi
    -   **lacchāmi**: i will receive
        -   **adantadamanaṃ vīraṃ, sabbasattasukhāvahaṃ
            lokanāthaṃ pūjayitvā, lacchāmi amataṃ dhanaṃ**
            By honoring the tamer of the untamed, the hero, the bringer of happiness to all beings,
            the Lord of the World, I shall obtain the deathless wealth
    -   **checchati**: he will cut
        -   checchati mārabandhanaṁ

    .table-of-contents a:hover {

    }

      transition: all 0.2s ease;
    }
    .toc-h3-list.collapsed {
      display: none;
    }
  `;
  document.head.appendChild(style);
  
  // Generate TOC
  const headings = document.querySelectorAll("h2, h3");
  if (headings.length === 0) return;
  
  const toc = document.createElement("div");
  toc.className = "table-of-contents";
  toc.innerHTML = "<h2>📖</h2><ul></ul>";
  const tocList = toc.querySelector("ul");
  
  let currentH2Item = null;
  let currentH3List = null;
  
  headings.forEach(heading => {
    if (heading.closest(".table-of-contents")) return;
    
    if (!heading.id) {
      heading.id = heading.textContent
        .toLowerCase()
        .replace(/[🇧🇷🇪🇸🇬🇧]/g, "")
        .replace(/[^\w\s-]/g, "")
        .replace(/\s+/g, "-");
    }
    
    if (heading.tagName === "H2") {
      // Create container for this H2 section
      const li = document.createElement("li");
      li.className = "toc-h2-item";
      
      // Add toggle arrow
      const toggle = document.createElement("span");
      toggle.className = "toc-toggle";
	toggle.textContent = "▶";  // Collapsed by default
      toggle.setAttribute("aria-label", "Collapse section");
      
      // Add the H2 link
      const a = document.createElement("a");
      a.href = `#${heading.id}`;
      a.textContent = heading.textContent;
      a.className = "toc-h2-link";
      
      // Container for H3 items (to be filled later)
      const h3Container = document.createElement("ul");
      h3Container.className = "toc-h3-list";
	h3Container.classList.add("collapsed");
      
	// Assemble
      li.appendChild(toggle);
      li.appendChild(a);
      li.appendChild(h3Container);
      tocList.appendChild(li);
      
      // Store references
      currentH2Item = li;
      currentH3List = h3Container;
      
      // Add click toggle functionality
      const toggleSection = () => {
        const isCollapsed = h3Container.classList.contains("collapsed");
        if (isCollapsed) {
          h3Container.classList.remove("collapsed");
          toggle.textContent = "▼";
          toggle.setAttribute("aria-label", "Collapse section");
        } else {
          h3Container.classList.add("collapsed");
          toggle.textContent = "▶";
          toggle.setAttribute("aria-label", "Expand section");
        }
      };
      
      toggle.addEventListener("click", function(e) {
        e.preventDefault();
        e.stopPropagation();
        toggleSection();
      });
      
      a.addEventListener("click", function(e) {
        // Allow normal anchor behavior, but also toggle if desired?
        // Comment out the next line if you want clicking the link to ALSO toggle
        // e.preventDefault(); 
        // Uncomment below to toggle when clicking the link text too
        // toggleSection();
        // Then scroll to heading
        // document.getElementById(heading.id).scrollIntoView({ behavior: "smooth" });
      });
      
    } else if (heading.tagName === "H3" && currentH3List) {
      // Add H3 item under current H2
      const li = document.createElement("li");
      const a = document.createElement("a");
      a.href = `#${heading.id}`;
      a.textContent = heading.textContent;
      li.appendChild(a);
      currentH3List.appendChild(li);
    }
  });
  
  // Insert TOC at the beginning of the page
  const firstHeading = document.querySelector("h1, h2");
  if (firstHeading) {
    firstHeading.parentNode.insertBefore(toc, firstHeading);
  } else {
    document.body.insertBefore(toc, document.body.firstChild);
  }
});
