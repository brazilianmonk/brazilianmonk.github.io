## Introduction

This chapter explains the different meanings (atthas) that can be expressed by case endings (vibhattipaccayas)


<a id="org3a1c1a6"></a>

### 2 vibhattipaccayatthas



-   **kāraka vibhattipaccayattha**: meanings of nominal case-endings that directly contribute to the production of an action &#x2013; kattu kāraka, etc
-   **akārakattha**: meanings of nominal case-endings that indirectly / do not contribute to the production of an action &#x2013; liṅgattha, ālapanattha, accanta-saṃyogattha, hetvattha, bhāvalakkhaṇattha, anādarattha, etc
-   notes:
    -   attha: meaning
    -   vibhattipaccaya: nominal case-ending (si, yo, aṁ, yo, nā, hi, etc)



-   kāraka &#x2013; meaning

    
    **kiriyaṃ karoti abhinipphādetīti kārakaṃ**: nominal (or verbal) vibhattipaccayatthas that directly perform, produce an action
    
    -   note: all kārakas are atthas, but not all atthas are kārakas
    
    
    
    -   6 direct-contributing kārakas &#x2013; meaning and list
    
        
        
        -   **kattukāraka** (agent)
        -   **kammakāraka** (object)
        -   **karaṇakāraka** (instrument)
        -   **sampadānakāraka** (recipient)
        -   **apādānakāraka** (place of separation)
        -   **adhikaraṇakāraka** (location; lit. container)
        -   note:
            -   also bhāvakāraka (action) from akhyātakaṇḍa (ākhyātavibhattipaccayattha)
        
        
    
    -   3 aspects of all kārakas
    
        
        
        -   **satti kāraka / kārakasatti** (ability, power): the ability of all 6 kārakas to perform an action (fundamental agent of the action)
        -   **dabba kāraka** (thing, substance): the substance that has the ability
        -   **sadda kāraka** (sound): the word that refers to the substance
        -   notes:
            -   all 3 can be called agent
                -   satti: real agent
                -   dabba: called agent by ṭhānyūpacāra
                -   sadda: called agent by kāraṇūpacāra
        
        **puriso** gāmaṁ gacchati
        
        -   the ability to go is the agent
        -   the man who has it is also the agent by ṭhānyūpacāra
        -   the word that refers to the man is also the agent by kāraṇūpacāra
        
        **kārakattā kriyāyeva, satti mukhyena kārakaṃ,
        dabbaṃ ṭhānyūpacārena, tadādhāraṇabhāvato**
        **atthassa vācako saddo, pyatthadvārena kārako** (bhedacintā)
        because it performs the action, power is primarily the kāraka,
        because it holds that power, substance is called kāraka by ṭhānyūpacāra
        the word that expresses the meaning, is also called kāraka because of its meaning
        
    
    -   definitions
    
        -   kattusatti: ability of the agent to perform an action
        -   kattukāraka: can refer to the kattusatti / dabba / sadda
        -   katvattha: agent meaning that can refer to the kattusatti / dabba
            -   attha cannot be sadda
        -   kāraka: what does the action which can be satti- / dabba- / sadda- kāraka
        -   kārakattha: satti- / dabba- kāraka
        
        (*:q: clarify*)
    
    -   10 upacāras: methods of naming things (extra)
    
        
        
        -   **phalupacāra** (result-designation): referring to a cause by the name of its result
            -   10 saddhamma: maggas, phalas, Nibbāna, and pariyatti
                -   pariyatti is called saddhamma because the result of pariyatti is magga, which is saddhamma
                    -   phala (result): maggas
                    -   pariyatti (cause): leads to 4 maggas
        -   **ṭhānupacāra** (location-designation): referring to something by the name of its location
            -   mañcā ukkuṭṭhiṁ karonti (the beds shout)
                -   mañcā: the people on the beds
        -   **ṭhānyūpacāra** (ṭhānī upacāra) (contained-designation): referring to a container by the name of what it contains
            -   puriso gāmaṁ gacchati
                -   man (ṭhāna, container): has the ability to go
                -   ability (ṭhānī, what is contained): the ability to go
        -   **kāraṇūpacāra** (cause-designation): referring to the result by the name of its cause
            -   cause: the attha purisa
            -   result: the word purisa, named so for referring to the attha purisa
        -   **bhedopacāranaya** (figurative separation): 2 functions that occur at the same time, that is, functions of identical temporal occurrence, may be expressed as though they occur at different times
            -   (*:q: clarify; maybe abhidhamma context, not grammar*)
            -   note: there are other upacāras
        
         

-   akāraka &#x2013; 2 types

    
    
    -   **indirect-contributing vibhattipaccayattha**: meaning that indirectly contribute to the action and is not present when the action occurs &#x2013; hetvattha
        -   saṅkhārapaccayā viññāṇaṃ
            -   saṅkhāras are connected and contribute indirectly to the arising of viññāṇa but are not present when the action of production occurs
        -   (*:q: is there any other?*)
    -   **non-contributing vibhattipaccayattha**: meanings disconnected from the action &#x2013; liṅgattha, ālapanattha, sāmīattha, bhāvalakkhaṇattha, niddhāraṇattha, etc
        -   sāmīattha: rañño putto gacchati (the king’s son goes)
            -   rañño: no connection with the action gacchati since the one who goes is the son, not the king

### vuttattha


when the meaning is mentioned, expressed (vutta) by the verb
puriso gacchati

-   gacchati: already expresses the agent
-   puriso: since the agent is already expressed by the verb, purisa is put it liṅgattha

    }

      display: none;
    }
  `;
  document.head.appendChild(style);
  
  // Generate TOC
  const headings = document.querySelectorAll("h2, h3");
  if (headings.length === 0) return;
  
  const toc = document.createElement("div");
  toc.className = "table-of-contents";
  toc.innerHTML = "<h2>📖</h2><ul></ul>";
  const tocList = toc.querySelector("ul");
  
  let currentH2Item = null;
  let currentH3List = null;
  
  headings.forEach(heading => {
    if (heading.closest(".table-of-contents")) return;
    
    if (!heading.id) {
      heading.id = heading.textContent
        .toLowerCase()
        .replace(/[🇧🇷🇪🇸🇬🇧]/g, "")
        .replace(/[^\w\s-]/g, "")
        .replace(/\s+/g, "-");
    }
    
    if (heading.tagName === "H2") {
      // Create container for this H2 section
      const li = document.createElement("li");
      li.className = "toc-h2-item";
      
      // Add toggle arrow
      const toggle = document.createElement("span");
      toggle.className = "toc-toggle";
	toggle.textContent = "▶";  // Collapsed by default
      toggle.setAttribute("aria-label", "Collapse section");
      
      // Add the H2 link
      const a = document.createElement("a");
      a.href = `#${heading.id}`;
      a.textContent = heading.textContent;
      a.className = "toc-h2-link";
      
      // Container for H3 items (to be filled later)
      const h3Container = document.createElement("ul");
      h3Container.className = "toc-h3-list";
	h3Container.classList.add("collapsed");
      
	// Assemble
      li.appendChild(toggle);
      li.appendChild(a);
      li.appendChild(h3Container);
      tocList.appendChild(li);
      
      // Store references
      currentH2Item = li;
      currentH3List = h3Container;
      
      // Add click toggle functionality
      const toggleSection = () => {
        const isCollapsed = h3Container.classList.contains("collapsed");
        if (isCollapsed) {
          h3Container.classList.remove("collapsed");
          toggle.textContent = "▼";
          toggle.setAttribute("aria-label", "Collapse section");
        } else {
          h3Container.classList.add("collapsed");
          toggle.textContent = "▶";
          toggle.setAttribute("aria-label", "Expand section");
        }
      };
      
      toggle.addEventListener("click", function(e) {
        e.preventDefault();
        e.stopPropagation();
        toggleSection();
      });
      
      a.addEventListener("click", function(e) {
        // Allow normal anchor behavior, but also toggle if desired?

      });
      
    } else if (heading.tagName === "H3" && currentH3List) {
      // Add H3 item under current H2
      const li = document.createElement("li");
      const a = document.createElement("a");
      a.href = `#${heading.id}`;
      a.textContent = heading.textContent;
      li.appendChild(a);
      currentH3List.appendChild(li);
    }
  });
  
  // Insert TOC at the beginning of the page
  const firstHeading = document.querySelector("h1, h2");
  if (firstHeading) {
    firstHeading.parentNode.insertBefore(toc, firstHeading);
  } else {
    document.body.insertBefore(toc, document.body.firstChild);
  }
});
