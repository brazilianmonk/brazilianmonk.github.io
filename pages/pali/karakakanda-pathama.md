## Meanings of paṭhamā vibhatti



-   **liṅgattha**
-   **ālapanattha**
-   note: other meanings appear later

  


<a id="org4353676"></a>

### liṅgattha



-   the mere meaning (attha) of the stem (liṅga)
    -   liṅgas express liṅgatthas, which can be paññatti or paramattha
        -   rūpa: liṅga referring to paramattha
        -   purisa: liṅga referring to hīnattha
-   liṅgattha is always present in any form of a noun but when only liṅgattha is to be expressed, without other meanings, or when the other meaning is vutta by the verb, the paṭhamāvibhatti is used
    -   liṅga: rukkha (the word)
    -   liṅgattha: rukkha (the real object)
    -   rukkha + si / yo > rukkho / rukkhā: only liṅgattha is expressed
-   note: the agent nature of rukkho is expressed by the verb, not rukkho itself

**rukkhoti vacanaṃ liṅgaṃ, liṅgattho tena dīpito
evaṃ liṅgañca liṅgatthaṃ, ñatvā yojeyya paṇḍito**
the word rukkho is a liṅga, the liṅga-meaning is expressed by it,
thus, knowing both the liṅga and its meaning, the wise person should employ them properly


-   3 definitions of liṅga

    
    
    -   **līnamatthaṁ gameti bodhetīti liṅgaṁ** (līna + √gam): makes known (bodheti) a hidden meaning (līnamattha) that if not enounced, would not be known by the listener
        -   līna here is considered a prefix added to the root gam
        -   this definition could be applied to verbs, but only nouns are included
    -   **līnaṁ aṅgaṁ liṅgaṁ** (līna aṅga): hidden component of all the forms of a word
        -   līna (hidden) because
            -   it is not used in the language
            -   it is not visibly present, is unmanifest (guṇavantu is hidden in forms like guṇavā, etc)
        -   aṅga (component) because it functions as a component of inflected forms
    -   **dhātu-paccaya-vibhatti-vajjitam-atthavaṁ liṅgaṁ**: that which has meaning but is not a root, suffix, or case
        -   dhātuvajjitaṁ: not a root
        -   paccayavajjitaṁ: not a suffix
        -   vibhattivajjitaṁ: not a case
        -   atthavantu: that which has a meaning
        -   notes:
            -   this definition can include upasaggas and nipātas as liṅga, but not verbs
            -   not verbs because they are verbal roots before the addition of verbal endings and become inflected forms (vibhatyanta pada)
    -   notes:
        -   **ye gatyatthā te buddhyatthā 
            pavatti pāpuṇanatthakā**
            whatever roots mean going also mean knowing
            -   adhigama: realization
            -   gameti: bodheti
    
    

-   2 types of liṅgattha and exception

    
    
    -   **suddha liṅgattha** (pure stem-meaning): stem-meaning not mixed with other meanings
        -   puriso: nominal meaning not mixed with other meanings like object, agent, instrument, etc
        -   with suddha liṅgattha, paṭhamāvibhatti is used
        -   includes the unmixed meanings of prefixes and particles
    -   **kammādi-saṃsaṭṭha liṅgattha**: stem-meaning mixed with other meanings such as kamma, karaṇa, etc
        -   so purisaṃ passati: purisaṁ (liṅgattha + kammattha)
        -   purisena odano bhujjate: purisena (liṅgattha + kattvattha)
        -   purisassa vatthaṃ dadāti: purisassa (liṅgattha + sampadānattha)
        -   purisassa putto: purisassa (liṅgattha + sāmīattha)
        -   exception: **vutta / utta vibhattiattha** (expressed case meanings): stem-meaning mixed with case meanings already expressed by the verb &#x2013; paṭhamāvibhatti is used
            -   purisena odano bhujjate
                -   odano: liṅgattha (+ kammattha) but is not in dutiyāvibhatti because the kammattha is actually already expressed by the verbal ending -te
            -   puriso odanaṃ bhuñjati
                -   puriso: kattvattha already expressed by the verbal ending -ti so the tatiyāvibhatti is not used
                    -   (*:q: is this the bhāvakāraka?*)
    
    **paṭhamā’vupasaggatthe, kesañcatthe nipātasaddānaṃ
    liṅgādike ca suddhe – bhihite kammādi-atthepi** (rūpasiddhi)
    the nominative is used in the meanings of prefixes, in meanings of some particles,
    in pure nominal meaning accompanied by gender and so on,
    and even in object and similar meanings when they are already expressed (abhihite)
    

-   why the paṭhamāvibhatti is used

    
    
    -   paṭhamāvibhatti only coveys the liṅgattha
    -   it is used since liṅgas cannot be used without case endings
    -   it makes the word usable since in Pāḷi only inflected form of words are used
        -   vibhattiyantaṁ padaṁ

### ālapanattha / āmantanattha


**ālapanatthādhike liṅgatthamatte**: there is one extra meaning, ālapana, merely in the meaning of the stem

-   ālapanattha (vocative meaning): shows the intention of addressing, calling, drawing the attention of someone or something toward oneself by using a noun or particle
    
    -   bho purisa:
        -   purisa: liṅgattha + ālapanattha using a noun
            -   paṭhamāvibhatti used in ālapanattha
                -   or in liṅgattha that contains ālapanattha
        -   bho!: ālapana using a particle
    
    

-   ālapanattha as a different nominal case ending

    
    sometimes considered as a different vibhatti due to its different declension
    

-   ālapanattha as akāraka in imperative

    
    ālapanattha is not the kattu of imperative
    
    -   bho putta, gāmaṃ gacchāhi
        -   putta: liṅgattha + ālapanattha
            -   akāraka since, at the moment of the address, it has no relation to the act of going
        -   kattu of gacchāhi: not explicitly stated; understood as tvaṃ referring to putta
    
    

-   6 types of ālapana

    
    
    -   **sajīva ālapana** (animate): bho purisa
    -   **nijjīva ālapana** (inanimate): jātaveda, paṭikkama
    -   **paccakkha ālapana** (visible): bho purisa
    -   **apaccakkha ālapana** (invisible, deceased, not present): kahaṃ, ekaputtaka!
    -   **niyama ālapana** (determinate): bho purisa
    -   **aniyama ālapana / dhammālapana** (indeterminate, calling the nature): acchariyaṃ vata bho! (my goodness! how wonderful!)
        -   an exclamation, not actually calling
        -   MV: brahma said "nassati vata bho loko vinassati vata bho loko" when the Buddha was unwilling to teach the Dhamma

    }
    .toc-h3-list.collapsed {
      display: none;
    }
  `;
  document.head.appendChild(style);
  
  // Generate TOC
  const headings = document.querySelectorAll("h2, h3");
  if (headings.length === 0) return;
  
  const toc = document.createElement("div");
  toc.className = "table-of-contents";
  toc.innerHTML = "<h2>📖</h2><ul></ul>";
  const tocList = toc.querySelector("ul");
  
  let currentH2Item = null;
  let currentH3List = null;
  
  headings.forEach(heading => {
    if (heading.closest(".table-of-contents")) return;
    
    if (!heading.id) {
      heading.id = heading.textContent
        .toLowerCase()
        .replace(/[🇧🇷🇪🇸🇬🇧]/g, "")
        .replace(/[^\w\s-]/g, "")
        .replace(/\s+/g, "-");
    }
    
    if (heading.tagName === "H2") {
      // Create container for this H2 section
      const li = document.createElement("li");
      li.className = "toc-h2-item";
      
      // Add toggle arrow
      const toggle = document.createElement("span");
      toggle.className = "toc-toggle";
	toggle.textContent = "▶";  // Collapsed by default
      toggle.setAttribute("aria-label", "Collapse section");
      
      // Add the H2 link
      const a = document.createElement("a");
      a.href = `#${heading.id}`;
      a.textContent = heading.textContent;
      a.className = "toc-h2-link";
      
      // Container for H3 items (to be filled later)
      const h3Container = document.createElement("ul");
      h3Container.className = "toc-h3-list";
	h3Container.classList.add("collapsed");
      
	// Assemble
      li.appendChild(toggle);
      li.appendChild(a);
      li.appendChild(h3Container);
      tocList.appendChild(li);
      
      // Store references
      currentH2Item = li;
      currentH3List = h3Container;
      
      // Add click toggle functionality
      const toggleSection = () => {
        const isCollapsed = h3Container.classList.contains("collapsed");
        if (isCollapsed) {
          h3Container.classList.remove("collapsed");
          toggle.textContent = "▼";
          toggle.setAttribute("aria-label", "Collapse section");
        } else {
          h3Container.classList.add("collapsed");
          toggle.textContent = "▶";
          toggle.setAttribute("aria-label", "Expand section");
        }
      };
      
      toggle.addEventListener("click", function(e) {
        e.preventDefault();
        e.stopPropagation();
        toggleSection();
      });
      
      a.addEventListener("click", function(e) {
        // Allow normal anchor behavior, but also toggle if desired?

      });
      
    } else if (heading.tagName === "H3" && currentH3List) {
      // Add H3 item under current H2
      const li = document.createElement("li");
      const a = document.createElement("a");
      a.href = `#${heading.id}`;
      a.textContent = heading.textContent;
      li.appendChild(a);
      currentH3List.appendChild(li);
    }
  });
  
  // Insert TOC at the beginning of the page
  const firstHeading = document.querySelector("h1, h2");
  if (firstHeading) {
    firstHeading.parentNode.insertBefore(toc, firstHeading);
  } else {
    document.body.insertBefore(toc, document.body.firstChild);
  }
});
